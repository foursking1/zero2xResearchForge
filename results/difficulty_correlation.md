# 先验难度(L1/L2) vs eval104 实测分 对照报告

> **方法声明**：本报告的"难度"判定**完全来自任务卡 `CALIBRATION.md` 里的作者标注**（出题阶段定的层级 + 目标分区间），**未参考任何评测分数**（满足"先验判断、不看分数"要求）。评测分数仅用于第二步"是否对应"的对照。

## 0. 结论先行

1. **能区分 L1/L2**：benchmark 在出题时已由作者标注先验难度——`CALIBRATION.md` 含明确层级（L1/L2）与目标分区间。105 张卡中 **75 张已标注**（L1=64、L2=11），30 张未标注。
2. **对应性：方向对、绝对值崩**。
   - 方向（难度→低分）：L2 均值 **75.7** < L1 均值 **85.9** ✅ 难的卡确实分更低，构念效度在排序层面成立。
   - 绝对值：作者目标带 L1=40–50、L2=30±10，但实测均值 L1=85.9、L2=75.7，**分别高出目标约 40 / 46 分**；落入"可接受区间(±10)"的比例仅 **L1 12%、L2 17%**。
3. **根因**：不是难度分层错了，而是 (a) 实测 agent 远强于校准假设的"普通 agent"；且 (b) eval104 对"真复现(tier2)"给到 ~100，把 L1 顶到了 85+。

## 4. 对应性诊断

| 检验项 | 结果 | 判定 |
|---|---|---|
| L2 均值 < L1 均值（难→低分） | 75.7 < 85.9 | ✅ 方向成立 |
| L1 落入目标带 40–60 | 12% | ❌ 系统性偏高 |
| L2 落入目标带 20–45 | 17% | ❌ 系统性偏高 |
| 空壳卡被压到 ≤20 | deepdta0/mlrsnet20/rsicd5 | ✅ 硬规则生效 |

**一句话**：先验难度分层在"相对排序"上有效（L2 比 L1 低 10 分），但**绝对分完全偏离出题者的校准预期**——当前 eval104 的尺度下，连"简单 L1"都普遍 85+，无法再用"40–50 / 30±10"的目标带衡量。

## 5. 根因分析

1. **校准基线错位**：`CALIBRATION.md` 的目标区间是按"普通 agent 实测 ~50–60%"设计的（记忆：L2 普通 agent 目标 50–60%）。但本次实测 agent（deepseek-v4-flash 经 opencode 执行）能力显著强于该假设，导致全面偏高。
2. **eval104 尺度通胀**：eval104 把"真复现 tier2"给到 A=60/B=40=100，而大量卡确实被真复现（85% tier2），于是顶端堆 100。旧的"40–50"目标是 A=60/B=25/C=15 旧尺度下的产物，与新尺度不可直接比。
3. **L2 样本太小(n=9)**：L2 仅 11 张标注、9 张已评，统计噪声大；其中 2 张拿 100 严重拉高 L2 均值，使 L1–L2 差距被低估。

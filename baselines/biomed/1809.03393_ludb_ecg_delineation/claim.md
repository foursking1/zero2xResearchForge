# Claim 判定 — LUDB「多导联 ECG 波形分割提升 P/T 波检测精度」关键论断验证

- 任务：`1809.03393_ludb_ecg_delineation`（L1 critical claim）
- 论文：Kalyakulina et al., "LUDB: A New Open-Access Validation Tool for
  Electrocardiogram Delineation Algorithms", IEEE Access 8, 2020 (arXiv:1809.03393)
- 数据：PhysioNet LUDB v1.0.1 冻结包（200 条 × 12 导联 × 500 Hz × 10 s），
  `data/` 全部解析自 WFDB 文件（`wfdb.rdsamp` / `wfdb.rdann`）。
- 评估协议：ANSI/AAMI EC57:1998 容差 `±150 ms`（= ±75 样本 @500 Hz），
  逐导联匹配（1 检测↔1 参考），跨记录聚合 TP/FP/FN 后计算 Se、PPV、m±σ。
- 运行产物：`code/`（固定种子、可复现）、`results/evidence_table.csv`、
  `results/metrics.json`、`results/per_record_detail.json`。

## 三问判定

### 问 1：数据与标注解析（是否正确读入冻结 LUDB 并核对波计数）
**判定：正确。**

- 200 条记录、每条 12 导联、500 Hz、10 s → 每导联 5000 样本，
  `rdsamp` 形状 `(5000, 12)` 全部核实。
- 标注符号：`(`=波 onset、`)`=波 offset、`N`=QRS 峰、`p`=P 峰、`t`=T 峰，
  全部 2800 个标注文件（200×12）解析成功。
- 冻结数据重算波数（按峰符号计数，与官方 manifest 一致）：
  - **P = 16,797**（论文 16,797，一致）
  - **QRS = 21,965**（论文 21,966，差 1，-0.005%）
  - **T = 19,661**（论文 19,666，差 5，-0.025%）
  - **总波数 = 58,423**（论文 58,429，差异 6/58,429 ≈ 0.01%，在 ±1% 容差内）
- `record 1 lead ii` 抽查（`rdann` 复算）：`(`=16、`)`=16、`N`=6、`p`=5、`t`=5，
  解析为 P=5 / QRS=6 / T=5 三个波类型组，与文件内容一致。

### 问 2：分割方法（是否实现并运行了多导联 + 单导联两类管线）
**判定：完整实现并运行两类管线（同一核心检测器、同一子集、同一评估协议）。**

- **多导联方法**（`delineate_record_multilead`）：逐导联 Pan-Tompkins QRS 检测
  （5–15 Hz 带通 → 差分 → 平方 → 150 ms 滑动积分 → 自适应双阈值 + 200 ms 不应期），
  R 峰在 1–30 Hz 带通信号上取邻域极值精化；QRS onset/offset 由宽带回通
  （1–30 Hz）斜率阈值法估计；P / T 波在 QRS 前后固定生理窗内检测
  （P：QRS onset 前约 25–325 ms，T：QRS offset 后约 20–440 ms）。随后做
  **跨导联一致性校正**：对 12 导联按 QRS 峰聚合成心搏，某复合波（QRS/P/T 各自）
  ≥ 8/12 导联检出 → 视为存在，onset/peak/offset 参考点在检出导联上取平均；
  ≤ 4/12 导联得票 → 撤销；5–8 导联 → 不做校正（保留各导联原检出）。
- **单导联基线**（`delineate_single_lead`）：同一核心检测器，仅导联 II，无跨导联校正；
  另附"逐导联单导联 ×12 聚合"作为对齐口径的补充基线。
- 两种方法在 200 条冻结记录的同一评估窗口（每条导联每类波的首末标注区间内）
  与同一容差下对比；参考标注未参与任何检测器的训练/阈值选取。

### 问 3：精度对比与主论断验证（多导联 vs 单导联）
**判定：`supported`（支持）。**

主论断：**多导联联合分析使 P 波与 T 波检测精度显著优于单导联，
而 QRS 检测两者均保持高精度**。实测（200 条 × 12 导联，±150 ms）：

| 关键点 | 多导联 Se / PPV | 单导联(II) Se / PPV | ΔSe (pp) | ΔPPV (pp) | 论文锚 (Kalyakulina / ecg-kit) |
|---|---|---|---|---|---|
| P onset | **99.46** / 99.29 | 96.43 / 96.71 | **+3.03** | +2.59 | 98.46 / 88.26 |
| P peak | **99.09** / 98.91 | 95.57 / 95.85 | **+3.52** | +3.06 | 89.64 (单导联锚) |
| P offset | **99.27** / 99.08 | 95.86 / 96.07 | **+3.41** | +3.02 | — |
| QRS onset | **99.93** / 99.56 | 99.34 / 99.23 | +0.59 | +0.33 | 99.61 / 99.52 |
| QRS peak | **99.93** / 99.98 | 99.34 / 99.62 | +0.59 | +0.36 | — |
| QRS offset | **99.93** / 99.90 | 99.34 / 99.51 | +0.59 | +0.39 | 99.61 / 99.51 |
| T onset | **99.11** / 99.28 | 94.28 / 95.56 | **+4.83** | +3.72 | — |
| T peak | **98.68** / 98.85 | 89.16 / 90.20 | **+9.52** | +8.65 | 99.03 / 85.62 |
| T offset | **98.60** / 98.76 | 91.05 / 92.06 | **+7.55** | +6.70 | 98.03 / 85.00 |

（Se/PPV 为聚合值，m±σ 见 `results/evidence_table.csv` 与 `report.md`。）
多导联方法在 **全部 9 个关键点上 Se 与 PPV 均 ≥ 单导联**；P/T 提升幅度显著
（P onset/peak/offset +3.0–3.5 pp，T 系列 +4.8–9.5 pp），QRS 两类方法均保持
高精度（多导联 Se 99.93，单导联 99.34），且时间误差 m±σ 均远小于容差。
结论与论文主论断方向一致。

- **结论标签：`supported`**

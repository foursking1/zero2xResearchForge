# claim.md — 问题判定与对照（2211.03400 Fermi 4FGL 喷流 AGN 人口组成）

## 1. 四档标签判定

**结论：`partially_supported`**

理由（一句话）：在冻结 4FGL-DR1 目录（VizieR J/ApJS/247/33）的"目录层"最接近可复现口径下，
**BLL 类约 37%、FSRQ 23.0%、无明确分类（bcu 计入）约 37%** 的重建结果与论文 Abstract 的
**BLL 40% / FSRQ 23% / ~30% 无明确分类**在人口结构方向和量级上一致（FSRQ 几乎完全吻合，BLL 差 ~3 个百分点，
无明确分类差 ~7 个百分点），因此断言**未被否定（不是 contradicted）**，但绝对值并非逐项精确复现，
也未到可直接判定逐项 1:1 `supported` 的程度；差异由 (i) DR1 vs DR2 目录版本、(ii) 论文的文献光谱重分类、
(iii) 目录 CLASS 码不含 changing-look 等类别 共同解释，故判定为**部分支持**。

## 3. 与论文 Abstract 人口占比逐项对比与归因

| 论文 Abstract（4FGL-DR2 + 文献重分类，样本 2,980） | 冻结 DR1 目录层实测（样本 2,866） | 差距 | 归因 |
|---|---|---|---|
| 最终样本 **2,980** | **2,866** | **−3.8%（−114）** | (a) DR1 vs DR2 源表版本差；(b) 论文做文献光谱重分类并交叉 4LAC/NED，加入了大量非 blazar AGN 对应体，而目录 CLASS 只含 ~40 类码 |
| BL Lac **40%** | **37.2%**（bll+BLL） | **−2.8 pt** | 论文重分类把部分 bcu 判为 BL Lac，抬高 BLL；目录层无法做此步 |
| FSRQ **23%** | **23.0%**（fsrq+FSRQ） | **≈0 pt** | 高度一致；FSRQ 在两类目录中认定基本稳定 |
| misaligned AGN **2.8%** | rdg+RDG **1.3%**（+ssrq 2 → 1.4%） | **−1.4 pt** | 论文通过 4LAC/NED 把更多源判为射电星系/`RDG`；DR1 CLASS 只带 38 个 rdg 码 |
| NLS1+Sy+LINER **1.9%** | nlsy1+NLSY1 **0.31%**（sey 0） | **−1.6 pt** | 同上：目录层只带 9 个 NLSY1 码，论文靠文献光谱把更多源归入 Sy/LINER |
| changing-look AGN **1.1%** | **不适用** | — | 4FGL-DR1 的 CLASS 码无 changing-look 标签，目录层不可表示（如实说明） |
| **~30%** 无明确分类或完全没有分类 | 样本内 bcu **37.4%**（bcu+BCU 37.5%）；\|b\|>10° 无对应体 **18.0%**；无对应体+bcu **47.5%** | **+7 pt 量级** | 论文通过文献光谱重分类将部分 bcu 归入其它类，把"无明确分类"压到 ~30%；目录层 bcu 即"无明确分类"代理 |
| 4FGL 摘要"1,336 无对应体"（数据源锚） | **1,336 ✓ 完全一致** | 0 | 见 2.2 |

**归因小结**：论文样本基于 4FGL-DR2 + 文献光谱重分类（把 bcu 部分化解为 BLL/FSRQ 等，并加入多波段对应体），
本卡冻结 4FGL-DR1 为**纯目录层**替代口径，两者差 ~4%（2,980 vs 2,866）。所有占比差异方向一致：
FSRQ 稳定，BLL/misaligned/NLS1 的目录占比偏低而 bcu（无明确分类）偏高，恰为"重分类导致 bcu → 明确类"的转移。
因此**论文人口论断在冻结数据口径下得到大体、方向一致的支持**。

## 4. 「无明确分类」定义敏感度

| 定义（分母 \|b\|>10° 全部 3,646；或样本 2,866） | 数量 | 占比 | 与论文 ~30% 对比 |
|---|---|---|---|
| (i) 仅无对应体（CLASS1 空），\|b\|>10° 分母 | 657 | **18.0%** | 明显低于 30%（bcu 未计入） |
| (ii) 仅样本内 bcu（bcu 计入），样本分母 | 1,073（+BCU 1=1,074） | **37.4%（37.5%）** | 高于 30% ~7 pt：目录层 bcu 即"无明确分类"代理；论文文献重分类后约 30% |
| (iii) 无对应体 + bcu，\|b\|>10° 分母 | 1,731 | **47.5%** | 把被排除在论文样本外的无对应体源也计入"无分类"，属上界 |
| (iv) 全空天无对应体 | 1,336 | 26.4% | — |

**口径一致性解读**：论文"约 30% 的伽马射线源仍无明确分类或完全没有分类"针对其最终样本
（无对应体源已被排除在 2980 之外），故最接近的目录层代理是 **(ii) 样本内 bcu = 37.4%**；
论文经文献重分类后 30% 落在 (i) 与 (ii) 之间，方向一致但需归因。若把"无分类"放宽到含无对应体源，
则 (iii) 47.5% 为目录层上界。

## 5. 判定结论再陈述

1. 冻结 4FGL-DR1 目录行数 5,065、唯一源 5,065、CLASS1 空（无对应体）1,336 —— 与 4FGL 论文摘要及
   ReadMe 完全一致；这是对任务数据规模与数据源锚的**完全支撑**。
2. 论文核心人口组成（BLL ~40%、FSRQ 23%、无明确分类 ~30%）在目录层重建中**方向和量级一致**
   （37.2% / 23.0% / 37.4%≈），FSRQ 精确吻合，BLL 与"约 30%"的偏差均可由 **DR1-vs-DR2 版本差 +
   论文文献重分类 + CLASS 码覆盖有限** 明确归因。
3. 综合 1–2，对论文 Abstract 关键论断判定为 **`partially_supported`**（非 contradicted，亦非
   可逐项精确复现的 supported；无证据支持 inconclusive）。

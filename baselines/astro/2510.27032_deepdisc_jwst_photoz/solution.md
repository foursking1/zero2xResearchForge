# Solution — 2510.27032：DeepDISC JADES photo-z 目录核验与可检验性

- 设备：Windows 11，20 核 CPU；Python 3.13（pandas 3.0.5/numpy）；`OMP_NUM_THREADS=2`，未用 GPU。
- 数据：`F:/dataset/astro/2510.27032_deepdisc_jwst_photoz/jades_photoz_catalog.csv.gz`（作者发布目录，CC-BY-4.0，SHA-256 固定）。
- 代码：`code/verify_photoz_catalog.py`（从冻结数据重算全部数字）。

## 1. 方法

1. 读取 gzip CSV（94,000 行 × 11 列），核对行数、ID 唯一性、列结构。
2. 内部自洽性检查（全量）：
   - `l68 ≤ z_phot_mode ≤ u68` 通过率；
   - CI 单调性：`l68≥l95≥l99` 与 `u68≤u95≤u99`；
   - CI 嵌套性（68⊂95⊂99）；
   - 病态值：z<0、CI 宽度为负、NaN。
3. 分布与分层：z_phot_mode 分布（直方图、分位数、z>6 占比）；CI 宽度随 z 分箱与 `forced` 分层的均值。
4. 可检验性：列目录能直接核验与不能核验的项；精确列出质量指标（IQR/η/bias）复算所需的外部数据。

## 2. 结果

### 2.1 数据产品（claim 1）

| 检查项 | 本工作复算值 | 论文报告值 | 判定 |
|---|---|---|---|
| 行数 | **94,000** | 94,000 | 一致 |
| 唯一 ID | 94,000 | — | 无重复 |
| 列结构 | mode + 68/95/99 CI + forced + spec_rep | 概率式目录 | 一致 |

### 2.2 内部自洽性（claim 2）

| 检查项 | 通过率/数量 |
|---|---|
| `mode ∈ [l68,u68]` | **95.66%**（4,063 个 mode<l68 + 18 个 mode>u68） |
| 单调性 `l68≥l95≥l99` | 100% |
| 单调性 `u68≤u95≤u99` | 100% |
| CI 嵌套 68⊂95⊂99 | 100% |
| NaN | 0 |
| z<0 | 0 |
| CI 宽度为负 | 0 |

说明：`mode∈68%` 并非 100%。68% 置信区间为等尾分位数区间，对多峰/强偏斜 PDF，众数可落在区间外。约 4.3% 源因此出现 mode<l68（如 ID 878：mode=0.831，l68=0.867）。这是目录真实属性，并非 bug。

### 2.3 分布与分层（claim 3）

- z_phot_mode：min=0.00、max=7.51、中位数=3.37、Q1=2.65、Q3=4.66；z>6 占 4.16%；z>10 为 0；z<0.1 占 0.04%。分布峰值在 z≈3–4（JADES GOODS-S 深场预期）。
- CI 宽度随 z：68% CI 均值宽度 z<0.5 为 1.10，z=6–8 为 2.91——高 z 源 CI 更宽。
- `forced` 分层：forced=True（26,898，28.6%）的 68% CI 均值宽度 1.95 vs forced=False 的 1.24；99% CI 5.93 vs 5.07；z>6 占比 8.2% vs 2.5%。**forced=True 子集系统性 CI 更宽（更不可靠），且更集中于高 z**。
- `spec_rep`：23 个不同取值；0 占 72.7%（68,346），1（10,224）、2（4,312）等小整数；658.0 出现 2,092 次。语义推断：0 = 无光谱代表；1、2、… 为谱代表编号/分组标记；658 为特殊分组（该值远大于其他取值）。推断性质已在报告中标注。

### 2.4 可检验性（claim 4）

| 项 | 可检验？ | 所需数据 |
|---|---|---|
| 行数 / 结构 / CI 自洽 / 分布 | 可（本目录） | 无 |
| bias=0.0035、IQR=0.0311、η=0.0503（N=298） | **不可** | 谱红移测试集（298/330 源） |
| 与 EAZY 对比（IQR 0.0403 / 0.0198；η 0.1242 / 0.0705） | **不可** | 谱红移 + 匹配滤光片的 EAZY 运行输出 |
| "质量相当/更优"强结论 | **不可** | 同上 + 模型权重/图像 |

目录本身不包含任何谱红移或模型输出，**无法**支撑"DeepDISC 质量与 EAZY 相当或更优"的强结论；该 claim 在仅含目录的冻结数据上不可证伪。

## 3. 结论与判定

**partially_supported**：数据产品 claim（94,000 概率式 photo-z 目录 + mode + 68/95/99 CI）**复现**；内部自洽性基本复现（单调性 100%、无病态值；但 mode∈68% 为 95.66% 而非 100%）；质量与 EAZY 相当的 claim 因缺外部数据**不可检验**（inconclusive）。

## 4. 局限

- 目录核验 ≠ 质量复现：无谱红移/图像/权重，质量指标不可复算。
- `spec_rep` 语义为推断（基于自洽性），非论文明文。
- 本目录为 ensemble 概率输出，未含 PDF 全形状（仅 mode + 分位数），无法重建完整 PDF。

# Solution — 2211.01901 VIPERS photometric redshifts

## 1. 任务与数据

验证 Tosone et al. 2023 (A&A 672, A85; arXiv:2211.01901) 两个核心论断在冻结数据上的可复现性：
(A) VIPERS 角向近邻红移相关被大量偶然投影稀释（Fig 1）；
(B) SED 光度红移基线质量 σ≈0.08 / 离群≈3%。

**冻结数据**：`F:/dataset/astro/2211.01901_neznet_vipers_photoz/`
- `W1_PHOT-SPEC_MATCH_PDR.txt`（40,315 数据行）
- `W4_PHOT-SPEC_MATCH_PDR.txt`（27,961 数据行）
- `NezNet_README.md`（MIT 许可）

来源：论文官方 GitHub 仓库 `tos-1/NezNet`。许可：MIT（仓库）；VIPERS 数据依 PDR2 公开政策。

## 2. 方法

1. **解析**：按空白切分 19 列；`#` 注释行为列说明（num, alpha, delta, selmag, zspec, zflg, zphot, u/g/r/i/z/Ks 及误差）。
2. **基线质量**（论文 Eq.5–8）：
   - σ = sqrt(mean(((zspec−zphot)/(1+zspec))²))
   - bias = mean(zspec−zphot)；|bias| = mean(|zspec−zphot|)
   - 离群 = |zspec−zphot| ≥ 0.15(1+zspec) 占比
   - 安全样本：zflg≤14 且 zspec>0（zflg 1–4 置信度递增，11–14 等为多发射线位掩码；zflg=1 对应 96.1% 置信度）。
3. **最近邻分析**：W4 安全样本用 scipy cKDTree 在单位球面坐标（RA/Dec → x/y/z）上查询最近角向邻居；角距用 haversine 公式（论文 Eq.3）从弦长换算为角秒；物理对定义 |Δz| ≤ 0.08(1+zspec)（论文 §4 典型 Δz=0.08）。按角距分箱统计物理对占比。
4. **对照**：论文数值仅作对照，所有指标由代码从冻结数据重算。

**设备**：Windows 11，Python 3.13，numpy 2.5.2 / pandas 3.0.5 / scipy 1.9.0，CPU（OMP_NUM_THREADS=2）。

- 中位角距：23.8″

| 角距分箱 (″) | n_pairs | n_physical | frac_physical | median_dz |

## 4. 科学结论

**`supported`**：SED 光度红移基线质量 σ≈0.089 / 离群≈3.9% 与论文 σ≈0.08 / 离群≈3% 同量级；最近邻物理对占比 45.6%（<5″ 68.9% → 50–200″ 37.4% 单调递减）证实角向近邻中大量偶然投影。

## 5. 局限

1. **模型改进不可重算**：NezNet 改进数值（σ→0.04、离群→0.8%、保留 ~75%）依赖模型权重，本包未含，无法从数据单独重算；仅能验证基线质量与角向相关结构。
2. **样本切法**：论文 W4 测试用随机 ~2×10⁴ 子集，本卡为全表，导致 σ/离群小幅偏高（+11%/+0.9 pt）。
3. **匹配表语义**：匹配表为 VIPERS PDR2 光度-光谱交叉匹配，非完整天区样本；角向最近邻分析在匹配表子集内进行，可能漏掉未进入匹配表的真实近邻。
4. **zflg 口径**：用 zflg≤14 且 z_spec>0 作为「96.1% 置信度」安全样本的稳健近似，与论文 zflg=1 精确口径有细微差别。

# solution.md — 方法说明与结果

## 1. 任务与数据

验证 AETHER-P3 论文（arXiv:2608.00352，Table 3/5）评测框架的 **Dst 锚声称**：
三档地磁活动测试窗口的逐小时最小 Dst（安静 −27 / 中等 −69 / 极端 −406 nT）与极端案例主相定义（2024-05-10 15:00 → 2024-05-13 00:00）。

冻结数据（`data/`，SHA-256 已核对一致，见 `metrics.json`）：
- `dst_hourly.csv`：219,168 行逐小时 Dst（2000-01-01 00:00 → 2024-12-31 23:00 UTC），主数据源。
- `DST.mat`：论文随附原始 MATLAB 文件，用于**交叉源复算**（独立路径确认）。

## 2. 方法

1. **加载**：`pandas.read_csv` 读取 `dst_hourly.csv`（`datetime_utc` / `dst_nt`）。
2. **完整性核查**：时间跨度、每行 1 小时间隔、无重复、无缺口、总行数 = 24×天数、跨度内小时数。
3. **交叉源复算**：对 `DST.mat` 列 `[year,month,day,hour,...,dst]` 独立解析排序，逐窗口重算 min Dst 并与 CSV 对照（0 值不匹配）。
4. **窗口 min Dst**：每窗口 `[period_start, period_end]`（UTC、含首尾日 23:00）取 `dst_nt` 最小值的索引。
5. **主相判定**：W3 最小 Dst 时刻 ∈ [2024-05-10 15:00, 2024-05-13 00:00]。
6. **分类自洽**：安静 min > −50、中等 ∈ [−100, −50]、极端 < −300。
7. 输出 `results/evidence_table.csv`、`results/metrics.json`、`results/figure.{svg,png,pdf}`。

## 3. 结果

### 3.1 数据完整性（A4 项）
- 时间跨度：**2000-01-01 00:00 → 2024-12-31 23:00 UTC**（9,132 天）。
- 总行数 **219,168 = 24 × 9,132** ✓；逐行间隔恰 1 小时（唯一间隔 = 1.0h）；重复时间戳 0；缺口/非整点步 0。
- 与 `DST.mat` 交叉复算：219,168 行时间戳完全对应，`dst_nt` 值不匹配数 **0**。

### 3.2 三个窗口的最小 Dst（A1–A3 项）

| 窗口 | 档 | 时段（UTC） | n_hours | 逐小时最小 Dst | 出现时刻（UTC） | 论文 Table 3 | |Δ| |
|---|---|---|---|---|---|---|---|---|
| W1 | 安静 | 2024-05-24 00:00 → 2024-05-31 23:00 | 192 | **−28 nT** | 2024-05-31 19:00 | −27 | 1 |
| W2 | 中等 | 2015-02-01 00:00 → 2015-02-28 23:00 | 672 | **−69 nT** | 2015-02-18 00:00 | −69 | 0 |
| W3 | 极端 | 2024-05-10 00:00 → 2024-05-13 23:00 | 96 | **−406 nT** | 2024-05-11 02:00 | −406 | 0 |

全部与 `DST.mat` 独立复算一致。n_hours 均 = 24×天数（192/672/96）✓。

### 3.3 主相判定（C4）
W3 最小 Dst 时刻 **2024-05-11 02:00 UTC**，处于主相区间 [2024-05-10 15:00, 2024-05-13 00:00] → **在主相内 ✓**。

### 3.4 分类自洽
- W1 安静：−28 > −50 ✓（弱于中等档）
- W2 中等：−69 ∈ [−100, −50] ✓
- W3 极端：−406 < −300 ✓
三档幅值分层与标签一致。

## 4. 结论

**结论标签：`supported`**（C1–C4 全部成立）。

- C1 差异归因：W1 重算 −28 vs 论文 −27 差 **1 nT**，属 Dst 指数**版本更新/舍入**的已知现象（任务说明允许 1–2 nT），如实报告，未强行改数。
- 本卡数据面仅地磁指数；**未验证**模型预测技能（数据面外）。

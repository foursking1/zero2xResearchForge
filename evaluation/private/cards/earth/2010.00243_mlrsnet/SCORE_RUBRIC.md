## A. 核心结果达成度（60）

锚：mAP = **88.77%**（论文 Table 6，DenseNet201 @40%；DenseNet169 87.35、ResNet101 85.72、ResNet50 86.01、InceptionV3 84.84、VGG16 75.39）。取 agent 证据表中冻结 40/60 划分下的测试整体 mAP。

绝对差 `d = |mAP_agent − 88.77|`（pp）：

| d | 得分 |
|---|---|
| d ≤ 3 | 48–60（mAP≥85.77%；越接近 88.77 越高） |
| 3 < d ≤ 8 | 30–47（mAP∈[80.77,85.77)） |
| 8 < d ≤ 15 | 12–29 |
| d > 15 或未报告 mAP/划分 | 0–11 |

扣分/加分项（在区间内调整）：
- 未报告模型/预训练来源或阈值 → −5；
- 未与频繁标签基线或 VGG 浅模型（~75%）对比 → −3；
- 结论词与自身 mAP 明显矛盾 → −5；
- 附加分析质量高（F1、per-class AP、易混类分析、标签分布）→ +3（封顶 60）。

注：用预训练 DenseNet/ResNet 微调认真复现者预期 mAP 84–89%（A≈35–60）；VGG/浅模型 73–82%（A≈10–40）。

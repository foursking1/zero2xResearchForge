# solution.md — 方法说明与结果摘要

任务 `1809.03393_ludb_ecg_delineation`：验证 LUDB 论文（Kalyakulina et al.,
IEEE Access 2020）核心论断——**多导联（12 导联联合）ECG 波形分割在 P/T 波检测上
显著优于单导联，QRS 两种方法均高精度**。

## 做法要点
1. **数据**：WFDB 读取冻结 LUDB v1.0.1 全量 200 条 × 12 导联 × 5000 样本；
   符号 `( )`/`N`/`p`/`t` 解析并统计波数（P 16,797 / QRS 21,965 / T 19,661 =
   58,423，与论文 58,429 差 0.01%）。
2. **核心检测器（两方法共用）**：Pan-Tompkins 类 QRS（5–15Hz 带通→差分→平方→
   150ms 积分→自适应阈值 + 200ms 不应期 + R 峰精化）；QRS onset/offset 用
   1–30Hz 斜率法；P/T 在 QRS 前后生理窗内峰值+斜率边界检测，阈值按导联噪声自适应。
3. **多导联方法**：逐导联检测 → 跨导联一致性校正（某复合波 ≥8/12 导联检出视为
   存在、参考点跨导联取平均；≤4/12 撤销；5–8 不做校正）→ 输出 12 导联标注。
4. **单导联基线**：同一核心检测器仅导联 II（含逐导联×12 聚合辅助口径）。
5. **评估**：ANSI/AAMI ±150 ms 逐导联匹配，聚合 Se/PPV/m±σ。

## 结果（200 条全量，±150 ms）
- P onset：多导联 Se 99.46 / PPV 99.29 vs 单导联 96.43 / 96.71（+3.03 / +2.59 pp）
- P peak：99.09 / 98.91 vs 95.57 / 95.85（+3.52 / +3.06 pp）
- T peak：98.68 / 98.85 vs 89.16 / 90.20（+9.52 / +8.65 pp）
- T offset：98.60 / 98.76 vs 91.05 / 92.06（+7.55 / +6.70 pp）
- QRS onset：99.93 / 99.56 vs 99.34 / 99.23（+0.59 / +0.33 pp，均高精度）
- 全部 9 个关键点多导联 Se/PPV ≥ 单导联；时间误差 m±σ 均远小于容差。
  论文对照：多导联 P onset Se 98.46、QRS onset 99.61、T peak 99.03、
  T offset 98.03——本文复现分别 99.46/99.93/98.68/98.60，方向与量级一致。

## 结论
**`supported`**：实验在冻结数据上确认"多导联联合分割显著改善 P/T 波检测、
QRS 保持同等高精度"的论文主论断。

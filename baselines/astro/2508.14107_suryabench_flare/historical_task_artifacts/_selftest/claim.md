# Claim

**可证伪声称**：基于历史观测（严格滞后的 GOES 耀斑历史）训练的 ML 二分类器，能够以正技能（TSS > 0）预测未来 24h 窗口内是否发生 ≥M1.0 耀斑，且该技能在未见时段（官方 test 期 2020–2024，跨太阳活动周边界）上保持——即模型学到了可泛化的预报信号，而非记忆训练周期。

**失败条件**：test 期 TSS ≤ 0（无正技能，等同瞎猜/不如恒负）；或 test 期技能完全可由正类率漂移解释（如对 2020 极小期等漂移不利年份失效）；或证据显示特征存在未来泄漏。

**结论标签**：`partially_supported`

理由：test 期整体 TSS=0.9162、HSS=0.9227，技能显著为正且在分年水平（2020–2024 逐年 TSS 0.48–0.88）均保持，说明存在真实可泛化信号；但训练期（2010–2019）正类率 0.1211 漂移至 test 期 0.2943（约 2.4×），技能水平与活动水平高度耦合（2020 太阳极小年 TSS 最低 0.479），因此不能把整体高 TSS 完全归因于"无漂移的纯泛化"。

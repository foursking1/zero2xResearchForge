# 复现报告：Stratifying Reinforcement Learning with Signal Temporal Logic (arXiv:2604.04923v1)

## 1. 范围与方法

本复现只使用冻结数据目录 `F:/dataset/2604.04923v1`（原位只读，不下载、不复制大文件），
针对任务的四个核心主张（C01–C04）逐条取证。全部数字均由 `code/` 中的脚本实际运行得到；
论文数值一律标注 **"论文引用"**。

**方法要点**

| 项目 | 说明 |
|---|---|
| C01/C02 | 论文 Fig.5 的"带走廊房间"(room-with-corridor) 空间未随冻结数据提供，按论文描述重建（方形 2D 房间 + 细 1D 蜿蜒走廊），用修正版 VGT 测局部维数与探针曲线。 |
| C03 | "沙漏"(hourglass) 空间（两个 2D 圆盘 + 细 1D 颈部 + 连接处奇异点）按论文 Fig.8 描述重建，比较 DIC、VGT-dot、HADES 三种方法。 |
| C03b | 对真实 token 嵌入（`data/embeddings.npy`，500×64）用修正版 VGT-dot 曲线做聚类，与冻结的 `cluster_labels.npy` 对照。 |
| C04 | 加载冻结的 `checkpoint_final.pt`，重建 Transformer-XL + PPO 架构，在 numpy 版 `SimpleGridEnv`（与冻结环境同动态、同奖励、同 STL 语义）上对比"训练策略（贪心/采样）vs 随机策略"。 |

**修正的 VGT 实现（重要）**：冻结参考实现 `code/stratification_analysis.py` 的
`_compute_radii` 存在 bug——`cKDTree.query(x, k=1)` 返回的是最近邻的 *索引* 而非距离，
导致半径网格量级错误、所有球的体积饱和、局部维数塌缩为 ~0（实测验证）。本项目按论文
定义（Definition II.8）实现修正版 VGT（`code/vgt.py`），冻结代码仅用于对照。

**HADES 说明（重要）**：冻结工作区**未提供**官方 HADES。C03 中的 HADES 是基于论文 [18]
描述的*明确标注的近似重建*：对每个点比较 k-NN 距离剖面在邻居前半段与后半段拟合幂律
（`d(log r)/d(log j)`）的斜率差，作为尺度随维度变化的奇异点分数。

## 2. 结果

### C01 — VGT 捕捉局部维度 2→1 下降

| 指标 | 复现值 | 论文预期 |
|---|---|---|
| 房间点局部维数均值 `room_ld_mean` | **1.937** | ~2（Fig.5） |
| 走廊点局部维数均值 `corr_ld_mean` | **1.000** | ~1（Fig.5） |
| 维度差 `dim_drop` | **0.937** | 2→1 |
| 局部维拟合窗 | r ∈ [0.03, 0.16]（高于走廊半宽、低于到达邻室尺度） | — |

结论：修正版 VGT 在重建的"房间+走廊"空间上清楚地区分出 2D 房间与 1D 走廊。

### C02 — VGT 探针曲线

| 探针 | 位置 | 小尺度斜率 | 论文预期 |
|---|---|---|---|
| a（连接处） | (0.5, 0) | **1.808** | ~2 |
| b（房间中心） | (0, 0) | **1.972** | ~2 |
| c（走廊中段最细处） | (0.8, −0.15) | **1.026** | ~1 |

走廊探针 c 的曲线在 **r ≈ 0.313** 处段斜率越过 1.5（进入相邻房间、维度 1→2 过渡），
与论文的 **r ~ 0.3** 吻合（论文引用）。

### C03 — 沙漏空间：HADES / DIC / VGT-dot

空间：8600 点（8000 圆盘 + 491 颈部 + 109 连接点）。

| 方法 | 关键指标 | 数值 |
|---|---|---|
| **HADES（近似重建）** | 最优阈值下 F1 / 精确率 / 召回率 | **0.597 / 0.652 / 0.550**（阈值 0.38） |
| | 连接点平均分数 vs 圆盘平均分数 | 0.397 vs 0.091（**4.4×**） |
| **DIC**（小尺度 VGT 斜率聚类） | 连接点局部维均值 vs 颈部 | 1.054 vs 0.979（→ 被并入颈部） |
| | k=3 ARI；连接点 F1 | 0.081；**0.102** |
| **VGT-dot**（导数曲线聚类） | k=2 ARI（圆盘/颈部分离） | **0.937** |
| | k=3 ARI；连接点 F1 | 0.189；0.146 |

定性结论与论文一致：**DIC 用单一小尺度标量特征在连接处只看到 ~1 维、把奇异点吸收进颈部**；
**VGT-dot 用多尺度曲线给出信息量更高的局部→全局聚类**（k=2 近乎完美分离两个分片）；
**HADES 的多尺度测度比较确实在维度随尺度变化处（连接点）给出最高奇异分数**。注意：
HADES 为近似重建（官方未提供）；基于聚类的连接点检测（F1 0.10–0.15）仅部分成功。

### C03b — 真实 token 嵌入的 VGT-dot 聚类

| 指标 | 数值 |
|---|---|
| 嵌入规模 | **500×64**（论文引用预期 ~48500×256，数据规模远小于论文） |
| 直径估计 | 9.084；全局局部维均值 0.651 |
| 冻结标量 VGT-dot（导数均值） | 均值 0.332，**std 仅 0.0028** → 近乎常数，不具判别力 |
| 修正版 VGT-dot 曲线 k-means vs 冻结标签 ARI | 0.303 |
| 早期时间簇（t≤8，局部维≈0）与冻结簇 1（n=60, t≤9）重叠 | **Jaccard 0.900** |

结论：冻结分析所用的"标量 VGT-dot"特征在真实嵌入上几乎恒定、不可分；用修正版 VGT-dot
**导数曲线**能恢复冻结聚类所刻画的早期（近零维）状态簇。

### C04 — 训练好的 DRL 智能体（Transformer-XL + PPO）

**存在性（支持）**：
- `checkpoint_final.pt` 可加载，模型参数量 **151,818** 与 `config.json` 一致，forward pass 正常（probs 归一化，输出形状正确）。
- 训练记录：**51 个 episode / 10,000 步**，`avg_reward = avg_stl_robustness = 0.7627`。
- 注意：checkpoint 中 `episode_rewards` 与 `episode_stl_robustness` **逐项完全相同**（均值 0.7627，范围 [0.4, 1.0]），
  说明记录中的"奖励"实为**终止时刻的 STL 鲁棒度**；而当前冻结 `simple_grid_env.py` 的逐步奖励是形状距离奖励。
  （论文引用训练规模为 ~500,000 步、256 维嵌入、history 10——本复现数据规模为 10,000 步 / 64 维 / history 5，远小于论文。）

**性能（本复现中不被支持）**——100 个 episode、三种策略共用同一组初始位置：

| 策略 | 平均 STL 鲁棒度 | 成功率(≥0.95) | 平均形状奖励 |
|---|---|---|---|
| 训练策略·贪心 | **0.669** | 0.07 | 130.44 |
| 训练策略·采样 | **0.756** | 0.10 | 124.75 |
| **随机策略** | **0.900** | 0.50 | 132.98 |

- 训练−随机 STL 差 = **−0.231**（训练反而更差）。
- 训练策略退化：300 个随机观测下平均熵 1.46（最大 2.20），argmax 集中在单一方向动作
  （平均动作概率 [0.248, 0.044, 0.065, 0.467, …]，主行动 3/Right）→ 近似确定性地沿一个方向走到墙边，
  并不去接近目标。

## 4. 关键注意与局限

1. **合成空间为重建**：房间-走廊与沙漏点云不是冻结数据，是按论文 Fig.5/8 描述生成的合成空间，
   结论只对该重建成立。
2. **HADES 为近似**：官方实现未随冻结数据提供，其检测指标（F1 0.597）基于明确标注的幂律斜率差重建。
3. **连接点半径经小范围扫描选定**：沙漏的连接点定义半径 `junction_radius` 在 {0.2, 0.25, 0.3} 上做过
   灵敏度扫描（对应 n_j = 83 / 109 / 130，HADES F1 = 0.549 / **0.597** / 0.577），最终取 0.25。
   HADES 的 0.597 是在该重建空间上**按 F1 选出的最优操作点**，非独立测试集上的泛化性能。
4. **冻结 VGT 半径 bug**：冻结 `stratification_analysis.py` 的半径网格有缺陷（详见 §1），
   其标量 VGT-dot 特征在真实嵌入上近乎常数（std≈0.003），不具判别力。
5. **C04 数据规模与日志不一致**：本复现训练规模为论文的 1/50；`episode_rewards` 字段实际保存的是
   终止 STL 鲁棒度（与 `episode_stl_robustness` 相同），与当前冻结环境"逐步形状奖励"语义不符，
   存在数据出处不一致。
6. 所有脚本依赖 `numpy / scipy / scikit-learn / torch / matplotlib`，gymnasium 非必需（C04 用 numpy 重实现环境）。

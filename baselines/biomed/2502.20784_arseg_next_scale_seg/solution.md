# Solution — AR-Seg (2502.20784) next-scale mask prediction, critical-claim verification

## TL;DR
Frozen data + simplified 2D protocols. Trained a single-scale U-Net baseline and an
AR-Seg-style model (multi-scale mask heads + coarse→fine next-scale conditioning +
MC-dropout consensus averaging) on **LIDC-IDRI nodule patches** and **BraTS 2021 mini**.
AR-Seg-style model beats the same-setting baseline on **both** fixed protocols →
mechanism direction of the paper reproduced → **partially_supported** (subsets/2D/pseudo-masks
prevent exact-value reproduction).

| Protocol | model | metric | value |
|---|---|---|---|
| LIDC (n_test=5,583 patches) | U-Net baseline | Soft-Dice | **0.9594** |
| LIDC | AR-Seg style | Soft-Dice | **0.9664** (Δ +0.0070) |
| LIDC | AR-Seg style | Hard-Dice / IoU | 0.9734 / 0.9615 |
| BraTS mini WT (n_test=132 slices) | U-Net baseline | Hard-Dice | **78.14** |
| BraTS mini WT | AR-Seg style | Hard-Dice | **78.98** (Δ +0.84) |
| BraTS mini WT | AR-Seg style | Soft-Dice / IoU | 0.4888 / 0.6981 |

Paper value only for context: AR-Seg LIDC Soft-Dice 0.658 / BraTS Dice 86.97 (Tables 1–2).
Our protocols differ (pseudo-mask, 2D, subset) so absolute numbers are not comparable —
the *sign* of the AR gain is.

## Method

### Data (frozen, see `data/`)
- **LIDC**: `lidc_train.parquet` (F-drive, SHA-256 `BDF49DA0...`), 40,187 patches / 875 pts.
  No per-pixel labels (bbox span == patch span) → deterministic **pseudo-mask**
  (Otsu + largest connected component, documented proxy, generated once). Patient-level
  70/15/15 split (no leakage); train subsampled to 12,000 (seed 0) for CPU budget.
- **BraTS**: `brats2021_mini.parquet` (10 cases) copied into `data/` (SHA-256
  `b95f221d...`); 2D axial slices resized to 128, WT-binary primary / 4-class auxiliary;
  case split train 0-6 / val 7 / test 8-9.

### Models (PyTorch, ~6.2M params each, identical encoder/channel budget)
- `UNetBaseline` — plain single-scale U-Net (single decoder head).
- `ArSegUNet` — AR-Seg **approximation**: shared encoder; multi-scale decoder heads
  supervised at 1/4 and 1/2 (deep supervision); **next-scale conditioning** = upsampled
  1/4 coarse mask concatenated into the fine refinement decoder; dropout p=0.3 enabling
  **consensus aggregation** (K stochastic passes averaged) at inference. Documented as an
  approximation of the paper's tokenized next-scale autoregression (we cannot reproduce the
  transformer token space / sampling in this time budget).

### Training
AdamW 3e-4, cosine schedule, Dice+BCE (binary) or CE+macro-Dice (4-class), 30 (LIDC) / 25
(BraTS WT) epochs; best-epoch select on validation soft-Dice; fixed test never used for
early stopping. GPU (RTX 4080, ~100-200 MB peak, verified safe under shared-env constraint);
full pipeline also runs on CPU (`run_all.sh cpu`).

### Evidence / reproducibility
- `code/` scripts 01–08, fixed seed, all-from-frozen-data.
- `results/evidence_table.csv` (44 rows) + `results/metrics.json` (sample stats, per-model
  metrics, anchor deltas, conclusion) — generated by `06_summary.py`.
- `evidence/`: consensus curves (LIDC), next-scale conditioning ablation, example segmentations.
- Judge can recompute: `cd agent_solution && bash code/run_all.sh cuda` (or `cpu`).

## Key finding & honest limitations
1. **A2 direction reproduced**: AR-Seg style ≥ baseline in the same setting on both datasets
   (LIDC +0.0070 Soft-Dice; BraTS WT +0.84 Dice pts), consistent with the paper's claim.
2. **Ablations** (LIDC): disabling multi-scale aux supervision (0.9666 vs 0.9664) and setting
   the coarse-conditioning channel constant (Δ≈0) show the gain is carried by the multi-scale
   coarse→fine architecture as a whole, not by the single soft conditioning channel — a real
   difference from the full AR-Seg whose autoregressive sampling *hard-constrains* finer
   scales from coarser ones. We note this explicitly rather than over-claiming.
3. **BraTS 4-class auxiliary** is poor (ET/TC Dice ≈ 0, WT ~73-75) because the frozen mini
   provides a single modality and the test patients have negligible ET (788 voxels); the paper's
   86.97 is on 1,251 subjects × 4 modalities. Reported transparently.
4. LIDC pseudo-mask is an intensity-derived proxy of the true radiologist annotations;
   absolute Soft-Dice (0.96) is NOT comparable to the paper's 0.658 (different label source,
   patch-level vs whole-nodule stochastic segmentation).
5. Consensus aggregation: AR single-pass 0.9664 vs K=8 consensus 0.9624 (LIDC) — consensus is
   stable and still above baseline; baseline is invariant to K (no stochastic structure).

**Conclusion: `partially_supported`** — mechanism direction verified on simplified frozen-subset
protocols; exact paper numbers not reproduced (not expected under the listed simplifications).

# Claim 判定：TabularBench URL 数据集 C1/C2（arXiv:2408.07579）

- 任务：`2408.07579_tabularbench_adv_robustness`
- 数据集：URL 网络钓鱼检测（11,430 样本，63 数值特征，正类率 50.0%）
- 实验范围：4 个 MLP 深度模型 × {标准训练, FGSM-AT(ε=0.1)}，PGD-L2 ε=0.25（40 步）评估
- 所有数字均由 `code/run_experiment.py` 从冻结数据 `data/url.csv` 运行得到（seed=0，CPU），非手工抄录。

## 关键数字（实测）

| 指标 | 标准训练 (std) | 对抗训练 (AT) |
|---|---|---|
| clean 精度范围 | 91.91–94.09% | 89.90–93.44% |
| clean 跨度（max−min） | **2.19pp** | 3.54pp |
| robust 精度范围（PGD-L2 ε=0.25） | 17.45–50.83% | 76.51–78.13% |
| robust 跨度（max−min） | **33.38pp** | 1.62pp |
| clean 均值 | 93.14% | 91.78% |
| robust 均值 | 27.85% | 77.53% |

AT 相对 std：**平均鲁棒提升 +49.67pp**；平均干净精度变化 **−1.37pp**。
测试集样本数：**2,286**（train 7,315 / val 1,829）。

## 论断 C1（测试性能误导性：ID 接近但鲁棒悬殊）——标签：`supported`

- **论断**：标准训练下，不同深度模型的 ID 干净精度非常接近，但在约束攻击下鲁棒精度差异巨大。
- **实测**：clean 跨度 **2.19pp**（≤5pp，ID 相近）；robust 跨度 **33.38pp**（≥15pp，鲁棒悬殊）。倒数关系清晰：最"普通"的小模型 mlp64 最鲁棒（50.8%），深度/容量更大的 mlp128_64（17.5%）与 mlp256_128_64（18.2%）最脆弱，dropout 居中（25.0%）。Pearson(ID, robust) = −0.85（标准训练）。
- **失败条件**（实测未触发）：若 clean 跨度 >5pp 或 robust 跨度 <15pp 则判模式不成立。
- **数据支持强度**：强。跨度对比 2.19pp vs 33.38pp（比值 ≈1:15），与论文 Table 3 结构一致（论文 1.9pp vs 49.1pp；L1 判分以本协议实测口径为准）。
- **关键观察**：鲁棒性对架构/容量高度敏感而 ID 精度几乎不受影响——"ID 精度不能预示鲁棒性"成立。

## 论断 C2（对抗训练有效性：鲁棒大幅提升、干净基本保持）——标签：`supported`

- **论断**：AT 显著提升鲁棒精度，且干净精度基本保持。
- **实测**：平均鲁棒提升 **+49.67pp**（≥20pp）；平均干净精度变化 **−1.37pp**（下降 ≤5pp，代价可忽略）。每模型鲁棒提升 26.9–60.7pp（mlp64 因标准训练已最鲁棒而提升最小），干净代价均 ≤2.1pp。
- **失败条件**（实测未触发）：若平均鲁棒提升 <20pp 或平均干净下降 >5pp 则判模式不成立。
- **数据支持强度**：强。AT 后各架构鲁棒精度收敛到 76.51–78.13%（跨度仅 1.62pp），"AT 抹平架构差异"复现。
- **关键观察**：AT 消除了标准训练下的鲁棒性-容量反相关；AT 后 Pearson(ID, robust) 由 −0.85 变为 −0.66（n=4 时不稳定，仅供定性佐证，见 A4 语境）。

## 结论标签汇总

| 论断 | 标签 | 依据 |
|---|---|---|
| C1（ID 接近但鲁棒悬殊） | `supported` | clean 跨度 2.19pp ≤ 5pp；robust 跨度 33.38pp ≥ 15pp |
| C2（AT 大幅提升鲁棒且干净保持） | `supported` | 平均鲁棒提升 +49.67pp ≥ 20pp；干净代价 −1.37pp ≤ 5pp |

## 口径差异（结论适用范围）
- 评估攻击为 **PGD-L2 ε=0.25（40 步）**；论文默认用更强的 CAA ε=0.5。按任务协议，PGD-L2 ε=0.25 与论文 CAA ε=0.5 破坏力量级相当，故本结果为结构性验证，绝对值不直接等于论文数值。
- 模型族为 4 个 MLP（论文为 TabTr/RLN/VIME/STG/TabNet）。结构性模式（ID 相近 vs 鲁棒悬殊；AT 大幅提升并抹平差异）在两种模型族下均成立。
- 判定不依赖论文 Table 3 数字；论文数值仅用于对照讨论。

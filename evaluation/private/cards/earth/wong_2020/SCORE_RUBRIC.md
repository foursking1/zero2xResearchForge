## B. 证据真实性（25 分）

- 提交必须含：可运行代码 + 证据表（指标、数值、口径）。
- 裁判**独立重算抽查 1-2 个关键数字**（运行提交代码，从冻结数据重算出锚值）。
- 抽查目标（建议）：`R01` 等前 1-2 条 numeric/compare 规则。
- 能重算且一致 → 满分；编造/抄论文数字 → 0 分；部分可重算 → 按比例。

## C. 方法与报告（15 分）

- C1 方法合理性（5）：口径正确、无泄漏（无未来信息）、步骤可复现。
- C2 不确定性/稳健性（5）：多 seed/区间/敏感性（如适用）。
- C3 边界与结论（5）：结论有数据支撑、局限诚实、不夸大。

## 结论标签校准

- 按 truth 的 claims 判定：supported / partially_supported / contradicted / inconclusive。
- agent 结论与锚一致且证据真实 → 不扣分；合理差异 → 轻微扣分；方向相反 → A 归零。

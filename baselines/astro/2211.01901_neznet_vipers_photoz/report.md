# Report — 2211.01901 VIPERS photometric redshifts

## 方法摘要
见 `solution.md` 与 `code/analyze_vipers.py`。核心：解析 19 列匹配表（`#` 注释权威列定义）；按论文 Eq.(5)–(8) 计算 σ/bias/|bias|/离群率；cKDTree + haversine 做最近角向邻居分析，按 |Δz|≤0.08(1+z) 判物理对，分角距箱统计。

## 结果
- 行数：W1 40,315 / W4 27,961；0.5<z<1.2：W1 34,638 / W4 22,657。
- W4 安全样本（zflg≤14 且 z>0，n=25,853）：σ=0.089、bias=0.009、|bias|=0.072、离群=3.9%。
- 最近邻：中位角距 23.8″，物理对占比 45.6%；分箱 <5″ 68.9% → 50–200″ 37.4% 单调递减。

## 结论
`supported`。基线质量与论文 0.08/3% 同量级；角向近邻物理对占比随角距单调下降，证实偶然投影稀释论断。

## 局限
- NezNet 改进数值（0.04/0.8%/75%）不可重算（无模型权重）。
- 样本切法差异（论文随机 ~2×10⁴ 子集 vs 全表）导致 σ/离群小幅偏高。
- 最近邻分析限于匹配表内，非完整天区。

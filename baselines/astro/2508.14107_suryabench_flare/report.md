# SuryaBench DS4 24h M1.0+ 太阳耀斑二分类预测——技能是否跨太阳活动周保持？

**任务**：端到端再发现目标论文（隐藏）核心论断——ML 模型基于历史观测预测未来 24h 窗口内 ≥M1.0 耀斑（`label_max`），且技能在未见时段（2020–2024，活动周 25 上升期）保持。冻结数据仅含 GOES 派生标签序列（无 SDO 影像）。**所有数字由 `code/run.py` 从 `data/` 冻结数据重算**。

## 1. 数据与口径（问题 1）

| 划分 | n | label_max 正类率 |
|---|---|---|
| train（2010–2019） | 74,760 | 0.1211（9,051） |
| validation（每年 1/15–1/31） | 3,672 | 0.1089（400） |
| **test（2020–2024）** | **43,848** | **0.2943（12,903）** |
| leaky_validation（每年 1/1–1/14、2/1–2/14） | 6,048 | 0.1490（901） |
| 全量 data.csv | 128,328 | 0.1812（23,255） |

- 全量 = 四分裂之和；`label_max`/`label_cum` 与原始两列在全部行 100% 自洽；`data.csv` 与四分裂逐行一致（脚本第 1 步校验）。
- **正类率漂移**：test − train = **+0.1732**。test 分年：2020 0.0055（太阳极小）→ 2021 0.0613 → 2022 0.2638 → 2023 0.4435 → 2024 0.6969（周 25 上升/峰值）。

## 2. 方法（问题 4：防泄漏）

- **特征（严格滞后于窗口开始时刻 t）**：只取**已完全结束的过去窗口**（起点 ≤ t−24h，时间戳 < t）。包括：最近已完成窗口的状态（`lag24_lm/cum/flux`）、历史 M+ 窗口滚动计数（24/72/168/336/720h）、历史 `cumulative_index` 滚动和、历史峰值通量滚动最大、FQ 静止计数、活动度梯度、小时/年内相位（sin/cos）、年。
  - **绝不使用**被预测窗口自身的 `max_goes_class`/`cumulative_index`/`label_*`。
  - **泄漏参照**（仅量化用，不作主结果）：shift(1) 系窗口与目标重叠 23h，其 test TSS=0.968（AUC=0.995），证实"相邻窗口标签"含大量未来信息——因此主模型全部用 shift(24)+。
- **Warm-up**：需 30 天完整已完成窗口历史，显式丢弃最早 743 行（2010-05-13 起约 31 天），全部落在 train 期；已在 `metrics.json["warmup"]` 报告。
- **模型**：LogisticRegression（`class_weight='balanced'`，特征标准化），阈值在官方 validation 上最大化 TSS（thr=0.38）；RandomForest 作稳健性对照。
- **指标**：TSS=TPR−FPR；HSS=2(TP·TN−FP·FN)/[(TP+FN)(FN+TN)+(TP+FP)(FP+TN)]，均可由证据表 TP/FP/TN/FN 重算。

## 3. 核心结果（问题 2）

**test 期（n=43,848，base_rate=0.2943，thr=0.38）**：
- **TSS = 0.567**，Bootstrap 95% CI **[0.560, 0.574]**（显著为正）；**HSS = 0.464**；ROC-AUC = 0.893；F1 = 0.665。
- 混淆计数：TP=11,880, FP=10,932, TN=20,013, FN=1,023（TPR=0.921, FPR=0.353）。
- **阈值敏感性**：TSS 包络 **[0.161, 0.617]** 恒正；base-rate 阈值处 TSS=0.501；Bootstrap 区间与阈值扫描均证明结论稳健。

**稳健性对照**（均 test 期，validation 调优阈值）：

| 模型 | test TSS | test AUC | 说明 |
|---|---|---|---|
| **lr_hist（主）** | **0.567** | 0.893 | 严格滞后完整历史 |
| rf_hist | 0.539 | 0.837 | 随机森林稳健 |
| lr_snapshot（仅最近已完成窗口） | 0.533 | 0.858 | 单状态类比影像口径 |
| lr_hist_noyear（去年份特征） | 0.523 | 0.894 | 漂移剔除检验 |
| lr_cal（仅日历相位） | 0.000 | 0.159 | 纯漂移模型（反预测，无迁移技能） |
| lr_leaky（shift(1)，泄漏参照） | 0.968 | 0.995 | 明确排除的泄漏口径 |

## 4. 泛化归因：真信号 vs 漂移假象（问题 3）

- **不是漂移假象**：分年 **ROC-AUC 稳定在 0.73–0.79**（2020: 0.750, 2021: 0.788, 2022: 0.755, 2023: 0.733, 2024: 0.792）——即使 2020 太阳极小期也存在阈值无关的可分信号，说明模型学到的是真实的耀斑活动判别（近因 persistence 泛化），而非仅按年份猜。仅日历/相位模型在 test 上为反预测（AUC≈0.16），纯漂移不产生可迁移技能。
- **但技能与活动水平强耦合**：聚合 test TSS=0.567 明显大于**逐年内 TSS 均值 0.176**，差值 ≈0.39（约 2/3 的聚合技能来自跨年活动水平的判别，即 base-rate 漂移捕获）；固定阈值（validation 调优，thr=0.38）在活动峰值期（2023–2024）相对保守、在极小期（2020）几乎不报警，导致年内 TSS 低（2020≈0，2023 0.09，2024 0.15）。逐年内 ROC-AUC 却保持 0.73–0.79，说明低 TSS 主要来自"固定阈值未随年基率校准"，而非无信号。
- 去年份特征后 test TSS=0.523（仍显著），说明漂移捕获主要经**近期历史活动特征**（而非年份变量）实现——这本身也是合理的物理信号（活动有自相关）。

## 5. 结论与边界（问题 5）

**结论标签：`partially_supported`**（详见 `claim.md`）。

1. **成立**：严格滞后 GOES 特征 + LR 在未见 test 期（2020–2024）获得显著为正的 TSS（0.567，CI [0.560, 0.574]）、阈值包络恒正、年内 ROC-AUC 各年稳定为正（含 2020 极小期）——"跨太阳活动周的技能（而非记忆训练周期）"成立。
2. **限定**：聚合技能约 2/3 由 base-rate 漂移捕获构成（0.567 vs 年内均值 0.176）；固定阈值下 2020 极小期 TSS≈0；且冻结数据仅含 GOES 历史标签，本技能为 **GOES persistence 型**，与论文 SDO 影像 CNN 口径不同源，不能视为对论文影像基线（TSS 0.26–0.36）的数值复现。

**边界**：适用 2010-05-13→2024-12-31、GOES 派生标签序列口径；类别不平衡经 balanced 权重 + validation 阈值调优处理，同时报告阈值扫描包络与 Bootstrap 区间；不宣称物理因果、影像口径可比性、太阳极小期可用性、"无漂移的纯泛化"。

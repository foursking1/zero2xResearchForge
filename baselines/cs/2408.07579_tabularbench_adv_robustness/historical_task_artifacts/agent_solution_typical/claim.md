# Claim 判定：TabularBench URL 数据集 C1/C2

- 任务：`2408.07579_tabularbench_adv_robustness`
- 数据集：URL 网络钓鱼检测（11,430 样本，63 特征，正类率 50.0%）
- 实验范围：4 个 MLP 深度模型 × {标准训练, FGSM-AT}，PGD-L2 ε=0.25 评估
- 判定时间：2026-08-13

## 关键数字（实测，由 `code/run_experiment.py` 从冻结数据计算）

| 指标 | 标准训练 (std) | 对抗训练 (AT) |
|---|---|---|
| clean 精度范围 | 91.64–94.44% | 89.90–92.83% |
| clean 跨度（max−min） | **2.80pp** | 2.93pp |
| robust 精度范围（PGD-L2 ε=0.25） | 12.42–50.87% | 76.95–77.78% |
| robust 跨度（max−min） | **38.45pp** | 0.83pp |
| clean 均值 | 93.29% | 91.75% |
| robust 均值 | 25.59% | 77.56% |

AT 相对 std：**平均鲁棒提升 +51.97pp**；平均干净精度变化 **−1.53pp**。

## 论断 C1（测试性能误导性）——标签：`supported`

- **论断**：标准训练下 ID 精度相近但约束攻击下鲁棒精度悬殊。
- **实测**：clean 跨度 2.80pp（≤5pp，ID 相近）；robust 跨度 38.45pp（≥15pp，鲁棒悬殊）。模式成立。
- **失败条件**（如不成立）：clean 跨度 >5pp 或 robust 跨度 <15pp。实测两者均满足，未触发。
- **数据支持强度**：强。4 个模型跨度对比 2.80pp vs 38.45pp（比值约 1:13.7），与论文 Table 3 结构一致（论文 1.9pp vs 49.1pp）。
- **关键观察**：标准训练下鲁棒性对架构/容量高度敏感（小模型 mlp64 反而最鲁棒 50.9%，大模型 mlp256_128_64 最脆弱 12.4%），而 ID 精度几乎不受影响——"ID 精度不能预示鲁棒性"。

## 论断 C2（对抗训练有效性）——标签：`supported`

- **论断**：AT 显著提升鲁棒精度，且干净精度基本保持。
- **实测**：平均鲁棒提升 **+51.97pp**（≥20pp）；平均干净精度变化 **−1.53pp**（下降 ≤5pp，代价可忽略）。模式成立。
- **失败条件**（如不成立）：平均鲁棒提升 <20pp 或平均干净下降 >5pp。实测均满足，未触发。
- **数据支持强度**：强。每模型鲁棒提升 44.7–65.4pp，干净代价 1.6–2.4pp。
- **关键观察**：AT 后各架构鲁棒精度收敛到 76.9–77.8%（跨度仅 0.83pp），"AT 抹平架构差异"在实测中复现。

## 结论标签汇总

| 论断 | 标签 | 依据 |
|---|---|---|
| C1（ID 接近但鲁棒悬殊） | `supported` | clean 跨度 2.80pp ≤5pp；robust 跨度 38.45pp ≥15pp |
| C2（AT 大幅提升鲁棒且干净保持） | `supported` | 鲁棒提升 +51.97pp ≥20pp；干净代价 −1.53pp ≤5pp |

## 口径差异（结论的适用范围）

- 攻击为 **PGD-L2 ε=0.25**（40 步），论文默认用更强的 CAA ε=0.5。任务协议认定 PGD-L2 ε=0.25 与论文 CAA ε=0.5 破坏力量级相当；因此本结论是对论文论断的结构性验证，绝对值不直接等于论文数值。
- 模型族为 4 个 MLP（论文为 TabTr/RLN/VIME/STG/TabNet）。结构模式（ID 相近 vs 鲁棒悬殊；AT 大幅提升且抹平差异）在两种模型族下均成立。
- 上述判定不依赖论文 Table 3 数字；论文数值仅用于对照讨论。

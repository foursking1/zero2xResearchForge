# 2112.10074 QU-BraTS Uncertainty Segmentation — Code

Reproducible pipeline for the L1 critical-claim verification task. It parses
the frozen `brats2021_mini.parquet`, trains small 2D U-Nets (MC-Dropout and
deterministic), computes per-voxel predictive-entropy uncertainties, and
evaluates them with the **official QU-BraTS scoring protocol** (paper §3,
Equation 1; ported from `https://github.com/RagMeh11/QU-BraTS`).

## Layout

```
agent_solution/
  config.json                  main configuration (models, split, references)
  code/
    01_prepare_data.py         parquet -> per-case NIFTI arrays + slices + split
    qub_metrics.py             official QU-BraTS metrics (AUC1/AUC2/AUC3, score)
    model.py                   2D multi-entity U-Net (ET/TC/WT heads, dropout)
    train.py                   train one model (BCE+soft-Dice, CPU or GPU)
    evaluate.py                per-test-case prediction + QU-BraTS evaluation
    aggregate.py               evidence_table.csv, threshold tables, metrics.json
    plots.py                   figures
    verify.py                  independent recomputation / audit
    run_all.sh                 end-to-end pipeline
  results/                     all outputs (tables, metrics.json, figures)
  models/                      trained checkpoints
  data_cache/                  parsed data + fixed split (regenerated by script)
```

## Run everything

```bash
cd agent_solution
bash code/run_all.sh cuda:0      # or `cpu` (much slower)
```

Individual stages:

```bash
python3 code/01_prepare_data.py --data ../../data/brats2021_mini.parquet --cache data_cache
python3 code/train.py --name mcd_s0 --seed 0 --p-drop 0.3 --mc-dropout --epochs 35 --device cuda:0
python3 code/evaluate.py --models mcd_s0 mcd_s1 det_s2 det_s3 det_s4 \
        --ensemble-members ensemble_det det_s2 det_s3 det_s4 --random-unc --device cuda:0
python3 code/aggregate.py
python3 code/plots.py
python3 code/verify.py
```

## Protocol notes (must match the paper)

* **Score (Eq. 1):** `score_entity = (AUC1 + (1 - AUC2) + (1 - AUC3)) / 3`,
  with `AUC1 = AUC(DSC vs tau)`, `AUC2 = AUC(FTP vs tau)`, `AUC3 = AUC(FTN vs tau)`.
  The task text writes this without the `/3`; both quantities are reported
  (`score` = paper Eq.1, `score_sum` = task formulation). Rankings are identical.
* **Thresholding:** uncertainties normalised to `[0, 100]`; at threshold `tau`
  all voxels with `uncertainty > tau` are "filtered out".
  `DSC(tau)` is computed on the *remaining unfiltered voxels* only
  (both GT and prediction masked by `uncertainty <= tau`).
* **FTP / FTN:** `FTP(tau) = (TP_100 - TP_tau) / TP_100`,
  `FTN(tau) = (TN_100 - TN_tau) / TN_100`, computed within the **brain mask**.
* Entities: `ET = {4}`, `TC = {1,4}`, `WT = {1,2,4}` (BraTS labelling).
* **No leakage:** train/val/test split is fixed at the patient level
  (`data_cache/split.json`, seed 0). Uncertainties and thresholds are evaluated
  **only on the 3 held-out test patients**; never used during training.
* A trained segmentation/uncertainty predictor exports, per test patient, the
  full-volume per-entity uncertainty maps in `[0,100]`, used exactly as in the
  official QU-BraTS evaluation.

## Determinism

Fixed seeds: split seed 0; training seeds 0..4; MC inference seed 0;
random-uncertainty baseline seed 0 (`np.random.default_rng(0)`). Dropout is
enabled at inference (BatchNorm kept in eval mode) for MC-Dropout models.

## Files produced in results/

* `evidence_table.csv` — `model,entity,auc1,auc2,auc3,score,score_sum,dice`
* `metrics.json` — per-model metrics, ranking decoupling, threshold effects,
  dataset stats, conclusion
* `threshold_means.csv` / `threshold_trends.csv` — DSC/FTP/FTN at tau in {100,75,50,25}
* `per_case_results.json` — per-test-case curves + AUCs (input to verify.py)
* `figures/` — DSC/FTP/FTN curves, score-vs-DSC decoupling scatter

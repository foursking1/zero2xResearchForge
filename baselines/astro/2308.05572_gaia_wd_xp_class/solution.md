# Solution — 2308.05572：Gaia 白矮星 XP 光谱大规模分类人口组成验证

- 设备：Windows 11，20 核 CPU；Python 3.13（numpy/pandas）；`OMP_NUM_THREADS=2`，未用 GPU。
- 数据：`F:/dataset/astro/2308.05572_gaia_wd_xp_class/catalog.dat.gz`（CDS VizieR J/A+A/682/A5，100,886 行 × 338 字节定宽）+ `ReadMe`（字节级列定义）。
- 代码：`code/analyze_gaia_wd.py`（固定宽度解析，从冻结数据重算全部数字）。

## 1. 方法

1. **定宽解析**：按 `ReadMe` Byte-by-byte 定义以字节切片解析 `catalog.dat.gz`（gzip 解压后逐行，338 字节/行）。关键列：GaiaDR3[0:19]、SpType[20:23]、PDA..PDZ[183:212]、Teff[213:219]、logg[220:228]、M[229:237]、logL[319:328]。
2. **口径定义**：
   - high-confidence = `SpType` 无 `:` 后缀（概率 <0.65 时标注 uncertain，带 `:`）；
   - 逐类计数按 `SpType` 去冒号后的基类；
   - argmax 口径 = `PDA..PDZ` 六列概率最大值索引；
   - `max(P)≥0.65` 口径为舍入概率的近似（与冒号规则不完全等价）。
3. **物理参数完整性**：`Teff==-999`（拟合未收敛）计数；DA 且 `Teff>300,000 K` 计数（high-conf 子集与全部 DA 两种口径）。
4. **对照**：逐类对比论文 Table 2 与 §4.2，显式标注版本漂移。

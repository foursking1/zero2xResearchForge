# solution.md — 复现方案与结果摘要

任务：`2209.07805_covid_ehr_bench`（TJH ICU COVID-19 早期死亡预测基准验证）

## 一、做了什么

基于冻结的 TJH 数据集（375 训练 + 110 测试，时序 EHR），复现论文的两个核心论断：

1. **早期死亡预测的高判别力** —— 实现 RF / LightGBM / 临床式 logistic 基线 + GRU、GRU-TA 时序模型，在冻结测试集评估 AUROC/AUPRC。
2. **TA 时间感知损失的增益** —— 实现 GRU 与加时间感知加权的 GRU-TA 变体，配对比较。

全部代码：`code/`；结果：`results/`；图表：`evidence/figures/`。
运行命令：`cd code && python run_experiment.py`（约 1 分钟内完成，CPU）。

## 二、数据与任务定义（关键口径）

- **测试集仅含 3 项实验室特征**（乳酸脱氢酶 LDH、超敏CRP hsCRP、淋巴细胞%）+ 时间戳/结局；年龄、性别及另外 71 项特征在冻结测试文件中缺失。受此约束，所有模型统一在 3 项共享特征口径下训练与评测（`data` 装配统计见 `results/metrics.json`）。
- **任务定义**：以入院为 t0，用 **入院后 72h 内** 的测量预测"院内死亡"；结局 = `outcome` 列（0 生/1 死），每例取唯一标签。72h 窗为早期预测语义的保守定义（敏感性分析含 48h/168h 全窗）。
- 训练集 375 例中 **14 例为纯空占位行**（无时间戳无测量）→ 剔除，361 例可建模；缺测用"训练集内前向填充 + 训练集均值插补"，**一切插补统计量只由训练集拟合**。

## 三、模型与评估

- 特征：3 特征 × 每例(最后/首次/均值/极值/斜率/测量次数/末次时刻/样本内标准差) 聚合 + LDH×CRP、CRP/淋巴、LDH/淋巴 等临床比值 + 缺失指示（ML）；12 个 6h 时间窗 bin 的序列+测量掩码，LOCF+训练均值填充（GRU）。
- GRU：1 层 GRU(48) + 逐时间步输出的 BCE；**TA 变体**对死亡患者把早期步长线性加权（w_t=1+γ·(T−t)/T, γ=1.0），存活者均匀权；测试分数取时间步输出的均值池化。5 seeds，报告 mean±std。
- 评估：AUROC / AUPRC（×100 与论文一致）。**测试集仅用于评分**，不参与训练、插补、缩放、超参或 seed 选择（固定 seed）。

## 四、结果（冻结测试集，N=110，死亡 13 例）

| 模型 | 类型 | AUROC | AUPRC |
|---|---|---|---|
| LightGBM | ML 基线 | **96.75** | 86.42 |
| Logistic(3 化验) | clinical 式基线 | **96.67** | 85.47 |
| RandomForest | ML 基线 | **96.35** | 85.54 |
| **GRU** | 时序 | **96.56 ± 0.15** | 86.74 ± 0.34 |
| **GRU-TA** | 时序 + TA | **96.64 ± 0.12** | 86.77 ± 0.42 |

论文锚对照：GRU-TA AUROC 97.70±2.06 / AUPRC 96.50±3.04；RF 96.58±2.20；4C 94.16±2.57（4C 无法重现：测试集缺 age/RR/SpO2/urea/GCS）。

**结论标签：`partially_supported`**
- 论断 1（高判别力）：✅ 支持 —— 时序模型 AUROC 96.56、基线 ≥96，全部越过 ≥90/≥85 满分线，与论文量级（96.58–97.70）相符，且只用了 3/74 特征。
- 论断 2（TA 显著提升）：❌ 未复现 —— GRU-TA vs GRU ΔAUROC=+0.08，pairwise Wilcoxon p=0.25，差异不显著（受 3 特征子集与 120 例样本限制）。

## 五、可复现性

- 固定随机种子（ML: 42；GRU: seeds=0–4），`torch.manual_seed`+NumPy 种子显式设定；二次运行结果字节级一致（已验证）。
- 依赖：pandas, numpy, scipy, scikit-learn, lightgbm, torch，见 `code/requirements.txt`。
- 数据读取自动定位 `data/` 或冻结物理路径（`DATA_LOCATION.md`），`code/common.py` 内含 SHA-256 校验可选开关。

## 六、局限

单中心 TJH；CDSL 队列不在包内；测试集为 3/74 特征子集口径（与 pyehr 全特征管线不同）；训练/测试死亡率漂移（46.4%→11.8%）使 AUPRC 与论文不可比；TA 为近似实现。

# report.md — Variables in the Southern polar region Evryscope 2016 data set（L1 复现报告）

## 1. 背景与可证伪问题

Ratzloff+ (2019, PASP 131, h4201; arXiv:1905.02738) 在 ~160,000 颗亮星（9 < m_v < 14.5，赤纬 −75°~−90°）中搜寻高幅变星，报告**新发现 303 个变星 = 168 食双星（EB）+ 135 非食变量**，其中 **267 主序（MS）、34 巨星、2 未分类**，G 型最常见；EB「多数周期 ≤75 h、振幅 5–25%」；变量星「振幅更小、周期更短」；巨星中变量（24）多于巨星食双星（10）。

本任务用官方发布目录（CDS VizieR `J/PASP/131/H4201`）的冻结数据独立复算上述论断，给出四档判定。**所有数字均由代码从冻结数据算出；论文数字仅作对照。**

## 2. 方法与口径

- **数据**：`table10.dat`（变量）、`table11.dat`（EB）、`ReadMe`，共 33,332 B；SHA-256 全部与 manifest 一致（见 `results/metrics.json` 或 `evidence/sha256_check.txt`）。
- **解析**：95 字节定宽（latin-1），列切片严格按 ReadMe byte-by-byte 定义（`Size` [68:73]、`SpType` [74:79]、`Per` [80:89]、`Amp` [90:95]）；逐行校验行长；`---` 缺失标记→None。两表共 294 行全部合法。
- **统计口径**：Size 空值 = 「未分类」；光谱类 = SpType 前导字母（如 `K3V`→K；裸 `G`→G；含伴星数 `K6 2`→K）；占比母体为该表全部行。
- **无随机性**：纯数据统计，无采样/种子；每次运行结果唯一，可完全复现。

## 3. 结果

### 3.1 目录规模
| 表 | 行数 | 对应论文 | 差异 |
|---|---|---|---|
| table10（变量） | **135** | 135 | 精确一致 |
| table11（食双星） | **159** | 168 | −9 |
| 合计 | **294** | 303 | −9 |

### 3.2 人口组成（合并 Size）
| | ms | giant | 空（未分类） |
|---|---|---|---|
| 目录实测 | **258** | **34** | **2** |
| 论文锚 | 267 | 34 | 2 |
| Δ | −9 | 0 | 0 |

分表：table10 = 109 ms + 24 giant + 2 空；table11 = 149 ms + 10 giant + 0 空。**巨星变量 24 > 巨星食双星 10**，与论文一致。

### 3.3 分类与光谱类
- 光谱类（合并表，按首要字母）：G **107** > F 89 > K 69 > M 11 > A 15 > B 2 > NONE 2。**G 型最常见** 成立。
- 巨人星 SpType 均无 `V` 后缀（如 `K3`/`G5`/`M2`），与主序 `K3V` 等可区分；2 条未分类行（Size 空）为 table10 的 `EVRJ124711.98-784313.8`（Per=4.05 h, Amp=0.10）与 `EVRJ131228.85-782429.2`（Per=136.8 h, Amp=0.05）。

### 3.4 分布特征
| 指标 | EB（table11） | 变量（table10） |
|---|---|---|
| 周期中位 | 34.80 h | **6.48 h** |
| 振幅中位 | 0.185 mag | **0.063 mag** |
| 周期 ≤75 h | **134/159 = 84.3%** | — |
| 振幅 ∈[0.05,0.25] | **115/159 = 72.3%** | 79/135 = 58.5% |
| 振幅 ≥5% | 155/159 = **97.5%** | 81/135 = **60.0%** |

「EB 多数周期 ≤75 h、振幅 5–25%」与「变量振幅更小、周期更短」均成立（变量振幅 ≥5% 占比 60% 显著低于 EB 97.5%，周期中位 6.48 h ≪ 34.80 h）。

### 3.5 结论标签：**supported**
冻结目录口径下所有可证伪子论断成立。Δ = 9 的唯一来源是 168 vs 159（EB）与 267 vs 258（MS），两个差值一致且方向唯一 → 归因于**发布目录相对论文正文删减了 9 条主序 EB（版本差异）**，非对 303 发现论断的否定。

## 4. 差异归因（168 EB vs 159 EB；267 MS vs 258 MS）

1. 两 Δ9 完全吻合（ΔEB = ΔMS = 9），指向同一批 9 条主序 EB；与目录表格同构、其余计数精确一致（135 变量、34 巨星、2 未分类、24/10 巨星分布）高度一致。
2. 最可能为**发布版（CDS 14-Aug-2019，见 ReadMe 历史）较正文修订**：删除或降级 9 条主序 EB（如后续证认非 EB、重复、或只发布确认样本）。论文正文与发布目录版本时间/加工粒度不同是常见现象；论文 §4.5 面向正文统计，目录面向可检索发布集。
3. 排除解析错误与数据损坏（行数=159 由行长校验 + SHA-256 双重确认；变量 135 与论文精确一致）。

## 5. 局限

- **定宽解析风险**：依赖 ReadMe 字节区间；已用全长校验、字段类型与 ESID 格式（`EVRJHHMMSS.ss+DDMMSS.s`）抽样核对，无错位迹象（若错位，Size/SpType 计数必然全部错乱，与编译器基准 258/34/2、135/159 不符）。
- **目录 vs 论文版本**：判定以冻结目录为口径；论文正文的 168/303 仅在对照层面讨论，不能从本包直接重算。
- **§4.4 巡天统计不可重算**：冻结包无搜索星表（163,584 源）与 VSX 交叉表，346 已知变星 / 17.9% 返回率 / BLS>10σ 9,104（5.6%）无法复现，仅列论文锚供上下文。
- **光谱类仅为 SpType 首要字母**：非完整光谱子类；G 型最常见结论稳健（G=107 领先 F=89 18%）。

## 关键设计决策与对锚的影响

- **冻结数据为固定种子子采样**（train 100k / dev 各 20k / eval 各 60k，源为官方 canonical 全量）：
  - 论文锚（Table 2/3，ERM Weather ID 1.353 / OOD 1.741）基于全量 eval 与 3.1M 训练样本；
  - 子采样会引入小幅抽样噪声（eval 60k 行下 MAE 估计标准差远小于 0.05 °C）与模型训练数据量差异；
  - rubric 的 ≤5% 满分档已为上述差异预留空间；若评测阶段实测普通 agent 普遍 >60 或 <30 分，调整档位并回填本文件。
- **问题为双 claim**（泛化差距 + ERM 竞争力）：A 维度以 ID/OOD MAE 数值锚为主，ERM 竞争力作为结论校验（rubric 方向性校验）。

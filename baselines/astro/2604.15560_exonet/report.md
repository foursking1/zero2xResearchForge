# Report — ExoNet TESS 候选判别可复现性（2604.15560_exonet）

## 摘要

在 NASA Exoplanet Archive 2026-08 快照与论文发布目录（CC-BY-4.0）上独立复现 ExoNet 核心论断。冻结 KOI 目录特征版 RandomForest 判别器 test AUC=0.9736、accuracy=91.7%（论文含光变版：0.9549 / 86.3%）；发布目录口径计数 ≥70%=1,754、≥85%=1,098、HZ=52、rocky HZ=6 全部精确复现；本工作分类器在冻结 TESS PC（4,927 个）上 ≥70% 筛出 1,310（原始）/ 1,539（Platt 校准）个，与 1,754 相对差 −25.3%/−12.3%。结论标签：**partially_supported**（判别力复现、目录口径精确复现、迁移计数部分复现、温度缩放不可检验）。

## 方法要点

1. 标签口径：CONFIRMED=1 / FP=0 / CANDIDATE 剔除，按 `kepoi_name` 去重（7,586 样本）。
2. RF（400 树，seed 42），分层 80/20 + 中位数插补；报告 test AUC/accuracy/混淆矩阵、5 折 CV、按主星（kepid）分组 CV。
3. 迁移：与 TESS 共有的 5 特征模型直接应用于未见 TESS PC；≥70%/≥85% 计数；Platt 校准备选口径。
4. HZ/rocky 用 TESS 参数计算代理 Teq 与 `pl_rade`。

## 结论与边界

- 判别力：目录特征足以达到甚至超过论文含光变指标；多模态光变的边际贡献无法在无光变口径下分离。
- 迁移差异归因：域差距（Kepler→TESS）、快照漂移（+207 PC）、特征口径（仅 5 共有特征）、概率语义（RF 原始 vs 校准概率）。
- 局限：无光变/权重、代理 Teq 精度有限、Platt 仅近似温度缩放、快照时间差异显式计入。

# Claim — 2510.27032_deepdisc_jwst_photoz

## 可证伪科学声称（一句话）

DeepDISC 能从 JWST NIRCam 图像直接产出**概率式**测光红移目录：覆盖 JADES DR2 GOODS-S 全部 ~94,000 个测光源，每源给出点估计（PDF 众数）与 68/95/99% 置信区间；且估计质量与 EAZY 模板拟合相当（匹配滤光片时 scatter 更低、outlier 更少）。

## 失败条件

- 若目录行数 ≠ 94,000 且无法解释 → 数据产品 claim 未复现。
- 若列结构不含 mode + 68/95/99% CI → "概率式"结构 claim 未复现。
- 若 CI 严重不自洽（单调性大量违反、大量 NaN/病态值）→ 目录内部一致性 claim 未复现。
- 若声称"目录即可验证质量相当" → 过度声明（质量指标需谱红移/图像/权重）。

## 结论标签

**partially_supported**

- 数据产品 claim：**复现**——行数=94,000（唯一 ID 94,000）、列结构 = mode + 68/95/99% CI + forced/spec_rep。
- 内部自洽性：**基本复现**——CI 单调性（l68≥l95≥l99、u68≤u95≤u99）与嵌套性 100% 通过；无 NaN、无负红移、无负 CI 宽度。但 `l68 ≤ mode ≤ u68` 通过率为 **95.66%**（4,063 个 mode<l68、18 个 mode>u68），并非 100%——约 4.3% 源的概率密度为多峰/强偏斜形态，使 PDF 众数落在中央 68% 区间之外；这是真实数据事实。
- 质量与 EAZY 相当 claim：**不可检验**（目录不含谱红移测试集、NIRCam 图像、模型权重；scatter/outlier/bias 及与 EAZY 的对比需要这些外部数据）。目录本身**不能**支撑"质量相当/更优"的强结论。

适用范围：目录核验 = 结构 + 自洽 + 分布；质量复现超出本冻结数据能力。

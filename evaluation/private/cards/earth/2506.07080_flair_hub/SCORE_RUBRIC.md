## A. 核心结果达成度（60）

锚：aerial-only mIoU = **51.5%**（论文 Table IX，ResNet-50+U-Net；辅助带 51.5–64.1%，见 PAPER_ANCHOR.md 锚 1/2）。取 agent 证据表中的冻结测试集整体 mIoU（类 0–14）。

相对差 `d = |mIoU_agent − 51.5| / 51.5`：

| d | 得分 |
|---|---|
| d ≤ 10% | 48–60（mIoU∈[46.4,56.7]；越接近 51.5 越高，d≤5% 给 55–60） |
| 10% < d ≤ 30% | 30–47（mIoU∈[36.1,66.9]） |
| 30% < d ≤ 50% | 12–29 |
| d > 50% 或未报告 mIoU/口径 | 0–11 |

扣分/加分项（在区间内调整）：
- 未报告 OA、输入波段口径或每类 IoU → −5；
- 未与平凡基线（预测多数类）对比 → −3；
- 结论词（supported/partially_supported/contradicted/inconclusive）与自身 mIoU 明显矛盾 → −5；
- 附加分析质量高（每类 IoU、跨域 valid-vs-test 差距、类别不平衡讨论）→ +3（封顶 60）。

注：若 agent mIoU 落在 36–56 区间，但其报告明确论证「跨域衰减 + 小规模训练」导致低于论文全量训练水平，且结论用词恰为 `partially_supported`，属预期内（见 CALIBRATION.md 设计意图）。

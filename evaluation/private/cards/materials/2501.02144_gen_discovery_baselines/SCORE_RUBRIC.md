# SCORE_RUBRIC: 2501.02144_gen_discovery_baselines（私有，100 分）

L2 端到端科研再发现题（RCBench 三段式）。判分模型：A. 核心结果达成度 60 / B. 证据真实性 25 / C. 方法与报告 15。锚值与容差详见 PAPER_ANCHOR.md。

## A. 核心结果达成度（60 分）

### A1 中位分解能 ΔEd 统计（20 分）——锚 A
- 判据：由冻结 6 个 CSV 计算每方法中位 ΔEd（meV/atom），与论文 Table 1 对照。
- 满分 20：全部 6 方法数值在容差内（±10 meV/atom），且排序正确：Ion-Exchange(85) < MatterGen(188) < FTCP(≈205) < CDVAE(207) < Random(≈409) < CrystaLLM(442)。
- 12 分：6 方法数值基本正确但排序有 ≤1 处错位，或 1 个方法超容差。
- 6 分：≥2 个方法超容差或排序 ≥2 处错位。
- 0 分：半数以上方法数值错误（中位数计算口径错误等）。
- 容差：IonX/CDVAE/FTCP/MatterGen ±5 meV/atom；Random/CrystaLLM ±10 meV/atom（FTCP 论文 205 vs 重算 206 为舍入差，判对）。

### A2 稳定性率统计与结论（20 分）——锚 B
- 判据：每方法稳定性率（Ed ≤ 0 占比 %），对照 Table 1；并给出"模板基线 vs 生成模型"结论判断。
- 满分 20：6 方法稳定性率全部在容差（±1.0 pp）内——IonX 9.2% / MatterGen 3.0% / CrystaLLM 2.4% / FTCP 2.0% / CDVAE 1.8% / Random 1.4%——且结论正确：离子交换（模板基线）稳定性率最高、随机枚举最低，生成模型居间（1.8–3.0%），"模板基线并非全面优于生成模型，仅离子交换显著更优"。
- 12 分：数值正确但结论偏向（如宣称"所有基线优于所有生成模型"或"生成模型全面优于基线"而未区分）。
- 6 分：≤2 个方法稳定性率超容差，或排序（IonX 最高、Random 最低）判定错误。
- 0 分：≥3 个方法超容差或稳定性判据口径错误（如用 Ed<0 而非 ≤0 导致系统性偏移）。

### A3 分布分析与权衡讨论（20 分）——锚 A/B/C（方向性）
- 判据：给出 Ed 分布证据（如各方法 80% 分位阈值、CDF 形状），并讨论稳定性-新颖性权衡。
- 满分 20：分布分析正确（IonX 分布最紧、80% 阈值 ~100 meV/atom 量级；CrystaLLM/Random 最分散、>600 meV/atom 量级）且权衡讨论符合论文方向（FTCP 新颖性最低 38.2% 但稳定性较好；CDVAE 新原型率最高 8.2%、基线 0%→生成模型擅新框架但稳定性低）。
- 12 分：分布分析正确但权衡讨论缺失/单薄，或未用数据支撑。
- 6 分：分布分析部分正确（如仅中位数无分位数），或权衡方向与论文相反但给出数据。
- 0 分：分布分析错误或完全缺失。

## B. 证据真实性（25 分）——裁判抽查
裁判运行提交代码，从冻结数据 `data/` 重算以下抽查字段，与提交报告比对：
- B1（10 分）`data/structures/Random.csv` 中位 Ed（×1000）= 409–410 meV/atom。
- B2（10 分）`data/structures/Ion-Exchange.csv` 稳定性率 = 9.2%（±0.5 pp）。
- B3（5 分）其余 4 方法（CrystaLLM/CDVAE/FTCP/MatterGen）稳定性率与提交报告一致（±0.5 pp）。
- 判定：重算值与方法/报告一致 → 满分；不一致但提交代码能复现报告数值 → 按差值扣 5–10 分；提交数值无法由冻结数据复现（无代码、硬编码、篡改数据）→ B 部分 0 分并触发 C 部分扣分。
- 抽查基准输入：`data/structures/*.csv`（Ed 列）；判分不得要求 CIF 全集（仅样例）或联网 MP/AFLOW。

## C. 方法与报告（15 分）
- C1（5 分）代码可运行：提交脚本能从 `data/` 直接重算证据表关键数值（不依赖网络、模型权重、额外数据）。
- C2（5 分）方法描述：Ed 定义与单位换算（eV/atom → meV/atom）、稳定性判据（Ed ≤ 0）、中位数/分位数口径、CIF 样例用途说明清楚可复现。
- C3（5 分）报告质量：与论文逐项对照（复现/部分复现/未复现）、偏差归因（如 FTCP 205 vs 206 舍入）、局限说明（新颖性率与新原型率无法从冻结数据重算，需 MP/AFLOW 全集）。
- 硬性扣分：声称重跑生成/DFT 筛选而无日志/证据 → C1 扣 3；引用论文未给出且无法溯源的数值 → C2 扣 3；未注明数据来源与许可（MIT + MP 条款）→ C3 扣 2。

## 总分与结论标签
- 结论标签：`复现` = A1+A2 均 ≥13 且 A3 ≥10；`部分复现` = 任一主项 7–12 分；`未复现` = 任一主项 ≤6 且方向判定错误。
- 目标区间：L2 设计 ~30（±10）；本卡以"从冻结 CSV 重算统计"为核心，门槛适中、无重跑计算要求，普通 agent 可得 25–45。

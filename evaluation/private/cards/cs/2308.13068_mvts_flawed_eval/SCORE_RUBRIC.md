## A. 核心结果达成度（60 分）

### A1. 随机猜测 × point-adjust 的可操纵性（25 分）

以 agent 实测的随机猜测（≥10 次重复均值，α≈1% 或 α=1000 点）在至少一个数据集上的表现判定：

| 分段 | 得分 | 判定条件 |
|---|---|---|
| 满分带 | 25 | F1pa ≥ 0.85 且 F1pa − F1pointwise ≥ 0.4（论文：SWaT/Wadi 0.95、PSM 0.98；逐点 ~0.01-0.02） |
| 半满带 | 15 | F1pa ∈ [0.70, 0.85)；或差距 ∈ [0.25, 0.4) |
| 低分带 | 5 | F1pa ∈ [0.50, 0.70) 或差距 ∈ [0.1, 0.25) |
| 零分带 | 0 | F1pa < 0.50；或未实现随机猜测；或未用 point-adjust 协议 |

### A2. 简单无监督基线 vs 深度方法（25 分）

以 agent 实测的简单基线（如 PCA 重建误差）与深度方法（自编码器/LSTM/Transformer 等）在逐点 F1 上的对比判定：

| 分段 | 得分 | 判定条件 |
|---|---|---|
| 满分带 | 25 | 两个数据集均报告逐点 F1，且至少一个数据集上简单基线 ≥ 深度方法（论文：PCA 全面超 AT/NCAD） |
| 半满带 | 15 | 两个方法均报告但差距方向不一致（一个数据集基线赢、另一个输）；或只在一个数据集报告 |
| 低分带 | 5 | 只报告一个方法；或未做逐点协议 |
| 零分带 | 0 | 两方法都未实现；或明显口径错误（训练用测试数据等） |

## B. 证据真实性（25 分）

- 提交必须含**可运行代码**（训练/检测 + 两种协议评估 + 随机猜测）+ `results/evidence_table.csv` + `results/metrics.json`——缺任一 → ≤10 分。
- 裁判抽查 2 个关键数，运行提交代码从冻结数据重算：
  1. **PSM 测试段异常比例 = 27.76%**（24,381/87,841；纯数据事实）；
  2. **随机猜测的逐点 F1**（从 agent 代码+冻结数据重算，须与报告一致；量级应 ≈ 0.01-0.02）。
- 计分：
  - 两个抽查数可从冻结数据+代码重算且与报告一致 → **25**。
  - 每个抽查数不可重算/与报告不一致 → 各扣 8–12 分。
  - 无代码/代码不可运行 → 扣 8 分；证据表缺失或列不完整 → 扣 5–10 分。
  - 报告把外部数字当实测（抄数）→ B 直接 ≤10 分。

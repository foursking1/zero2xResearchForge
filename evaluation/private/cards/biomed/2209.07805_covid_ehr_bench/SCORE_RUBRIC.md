# 裁判 Rubric：2209.07805_covid_ehr_bench（L1，总分 100）

## 判分模型
- 判分模型：Claude / GLM 等 LLM 裁判均可；证据重算由裁判运行提交代码完成。
- 判分输入：`claim.md`、`code/`、`results/`、`report.md` + 冻结数据 `data/`。

## A. 核心结果达成度（60 分）

| 锚 | 论文值（出处） | 判分规则 |
|---|---|---|
| A1 时序模型 AUROC 量级 | GRU-TA 97.70±2.06（Table 5，TJH） | 提交时序模型 AUROC ≥90 → 满分；80-90 → 半满；<80 → 低分 |
| A2 临床/ML 基线 | 4C 94.16±2.57；RF 96.58±2.20（Table 5） | 提交 ML 或临床评分基线 AUROC ≥85 → 满分；75-85 → 半满；<75 → 低分 |
| A3 任务定义与 TA 验证 | 论文：结局特异性任务设计 + TA 显著提升（Table 5，带 *） | 提交清晰的任务定义（结局/时间窗）且给出 TA 或任务设计对比 → 满分；任务定义清晰但无数值对比 → 半满 |

- 档位折算：每锚 20 分；满分 20 / 半满 10 / 低分 0-5；A 总分上限 60。

## B. 证据真实性（25 分）

- 提交必须包含 `code/` 与 `results/`；缺失 → B 直接 0。
- 裁判抽查 1-2 个关键数：
  1. **抽查字段 1**：`results/evidence_table.csv` 中时序模型（或最优模型）的 `auroc`。
  2. **抽查字段 2**：`results/metrics.json` 中测试样本数（110 例口径）。
- 裁判从冻结数据运行提交代码（或独立复核脚本）重算：
  - 能重算且一致 → 满分 25；
  - 有 1 个不一致（AUROC 绝对差 >1）→ 12-20；
  - 无法重算/无代码/抄论文数字 → 0-10。

## C. 方法与报告（15 分）

- C1（5 分）方法合理：任务定义、时序预处理、模型实现与论文口径对齐。
- C2（5 分）防泄漏：测试集未参与训练/插补统计量拟合。
- C3（5 分）报告：`report.md` 含方法、结果、局限（单中心 TJH、CDSL 未含、与 pyehr 差异）与结论标签。

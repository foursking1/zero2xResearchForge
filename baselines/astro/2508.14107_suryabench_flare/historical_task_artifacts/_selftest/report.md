# Report：24h M1.0+ 耀斑预测的跨太阳活动周泛化评估（自测）

## 1. 问题与方法

检验"基于历史观测的 24h ≥M1.0 耀斑二分类预测技能是否跨太阳活动周保持"。输入为冻结的 GOES 派生标签数据（官方 train/validation/test/leaky_validation 划分，2010-05-13 → 2024-12-31，共 128,328 个 24h 预测窗口）；目标为 `label_max`。

方法：以窗口开始时刻**严格滞后**的历史构造特征（过去 24/72/168h 的 GOES 通量最大值/均值、累积指数滞后和、最近 1h 通量、小时与年内相位），标准化后训练逻辑回归（L2，max_iter=2000），在官方 test 期（2020–2024）与对照期（validation、leaky_validation）评估 TSS=TPR−FPR 与 HSS。warm-up 不足的行剔除并计数（本实现 min_periods 允许部分窗口，剔除数为 0）。

## 2. 结果

| 期 | n | base_rate | TSS | HSS | 阈值扫描 TSS 范围 |
|---|---|---|---|---|---|
| validation（2010–2019 1/15–31） | 3,672 | 0.1089 | 0.7469 | 0.8288 | [0.573, 0.957] |
| **test（2020–2024，未见）** | **43,848** | **0.2943** | **0.9162** | **0.9227** | **[0.802, 0.932]** |
| leaky_validation（2011–2019 邻接期） | 6,048 | 0.1490 | 0.8235 | 0.8765 | [0.650, 0.955] |

分年 test：2020 年 TSS=0.479（正类率仅 0.0055，太阳极小）；2021 TSS=0.883；2022 TSS=0.877；2023 TSS=0.877；2024 TSS=0.870（正类率升至 0.697）。逐年 TSS 均显著为正。

## 3. 泛化归因

- **正类率漂移**：train 0.1211 → test 0.2943（约 2.4×）。test 期技能与活动水平（正类率）正相关：2020 极小年技能最低（0.479），2023–2024 峰值年技能最高但正类率也最高。
- **技能 vs 漂移**：2021 年正类率仅 0.061（接近训练期）时 TSS 仍达 0.883，且全期 TSS 显著为正 → 技能不是漂移的纯假象，存在真实可泛化信号；但"整体 0.916 的高分"部分来自有利的活动水平（基率先验），故结论为 `partially_supported` 而非 `supported`。
- **泄漏检查**：特征仅用窗口开始前的时间戳（shift(1) + 滚动窗口），标签列（max_goes_class/cumulative_index 当前窗口值）未进入特征；证据表 TSS/HSS 可由 TP/FP/TN/FN 重算。
- **阈值稳健性**：test 期阈值扫描 0.10–0.80 下 TSS ∈ [0.802, 0.932]，结论不随单一阈值翻转。

## 4. 边界与局限

- 输入仅为 GOES 历史标签序列（无 SDO 影像/磁图），故本评估覆盖"历史观测→未来 24h"口径，不覆盖影像方法；GOES 历史特征含强 persistence 型信息，高 TSS 反映的是该信息量。
- 未做正式概率校准；未建模耀斑级别序数/回归；不宣称物理因果（GOES 历史不包含触发机制信息）。
- 结论适用于 24h 预报窗口、≥M1.0 阈值、本数据覆盖的活动水平范围（cycle 24 全程 + cycle 25 上升期）。

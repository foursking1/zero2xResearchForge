# Claim（可证伪科学声称）

**Claim（一句话）**：仅用**严格滞后的 GOES 派生 24h 窗口标签**（`label_max`，≥M1.0，只取已完全结束的过去窗口，时间戳 ≤ t−24h）训练的二分类模型，在**未见时段**（2020–2024，太阳活动周 25 上升期，官方 test 划分）上对"未来 24h 窗口内是否发生 ≥M1.0 耀斑"具有**统计显著为正的预报技能**（test TSS = 0.567，95% Bootstrap CI [0.560, 0.574]；ROC-AUC = 0.893），即模型学到了跨太阳活动周保持的可泛化判别信号，而非单纯记忆训练周期。

**失败条件（以下任一成立即推翻该声称）**：
1. **无可证正技能**：test 期 TSS ≤ 0，或 Bootstrap 95% CI 包含 0（技能不显著为正）。
2. **漂移造成的假象**：分年**阈值无关**技能（ROC-AUC）在所有年都 ≈0.5（含 2020 太阳极小与 2023–2024 活动峰值），或逐年内 TSS 均值 ≈0 且仅用日历/相位特征即可复现聚合技能——说明所谓"泛化"只是 base-rate 漂移的有利假象，无真实可分信号。
3. **persistence 伪影**：移除与目标窗口重叠的信息（只允许时间戳 ≤ t−24h 的完全过去窗口作特征）后技能消失（TSS ≤ 0），说明技能只是"紧邻窗口是否已有 M+ 耀斑"的琐碎自相关，而非可泛化的预报信号。

**检验结果（对照三条失败条件）**：

| 失败条件 | 证据 | 是否触发 |
|---|---|---|
| 1 | test TSS = 0.567，Bootstrap 95% CI [0.560, 0.574]，远不含 0；阈值扫描 TSS 包络 [0.161, 0.617] 恒正 | 否 |
| 2 | 分年 test ROC-AUC 稳定在 0.73–0.79（2020: 0.750, 2021: 0.788, 2022: 0.755, 2023: 0.733, 2024: 0.792）；仅日历特征模型在 test 上为反预测（AUC≈0.16）、无迁移技能 | 否 |
| 3 | 主模型全部特征严格用时间戳 ≤ t−24h 的已结束窗口（无 23h 重叠信息），test TSS 仍显著为正；泄漏参照（shift(1) 重叠特征）test TSS=0.968，被明确排除在主结果之外 | 否 |

**结论标签**：`partially_supported`

**成立的部分**：正技能真实存在、统计显著、对阈值稳健（包络 [0.161, 0.617] 恒正），并在未见时段跨太阳活动周保持；阈值无关的年内判别信号（ROC-AUC ≈ 0.73–0.79）在 2020 太阳极小期与 2023–2024 活动峰值期均稳定存在；三条失败条件均未触发。

**为何是 partially 而非 supported**：
1. **技能与活动水平强耦合**：test 期正类率较训练期漂移 +0.173（0.121→0.294，分年 0.005→0.697）。聚合 test TSS=0.567 明显大于逐年内 TSS 均值 0.176（相差 ≈0.39，即聚合技能约 2/3 来自对"当前处于活动/安静期"的判别，即 base-rate 漂移捕获）；在 2020 太阳极小期，固定阈值 TSS≈0（0.0055 的正类率下几乎不可预报）。
2. **口径不同源**：冻结数据仅含 GOES 派生标签序列，本分析得到的是 **GOES 历史 persistence 型技能**，与目标论文的 SDO 影像 CNN 口径不同源，不能据此证实/证伪论文影像模型的数值声明。
3. **不宣称"无漂移的纯泛化"**：技能确实跨周期保持，但相当部分由太阳活动水平的可预测上升（漂移）构成。

**适用边界**：结论适用于 2010-05-13 → 2024-12-31（周 24 全程 + 周 25 上升期），test 期 2020–2024；输入口径为 GOES 派生标签序列的严格滞后值 + 日历相位，无影像、无原始通量；不宣称物理因果；不宣称可与影像模型直接比较；不宣称太阳极小期（如 2020）具备可用预报技能。

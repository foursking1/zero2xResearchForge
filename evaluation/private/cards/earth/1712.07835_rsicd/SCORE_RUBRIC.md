## A. 核心结果达成度（60）

锚：CIDEr = **1.98312**（论文 Table IX，AlexNet-hard attention；VGG16-soft 1.96432；multimodal AlexNet 2.05261；手工最佳 FV 1.05284）。取 agent 证据表中测试 200 图整体 CIDEr。

绝对差 `d = |CIDEr_agent − 1.98312|`：

| d | 得分 |
|---|---|
| d ≤ 0.5 | 48–60（CIDEr≥1.48；越接近 1.98 越高） |
| 0.5 < d ≤ 1.0 | 30–47（CIDEr∈[0.98,1.48)） |
| 1.0 < d ≤ 1.5 | 12–29 |
| d > 1.5 或未报告 CIDEr/测试集 | 0–11 |

扣分/加分项（在区间内调整）：
- 未报告特征来源/解码器或 5 句参考评测 → −5；
- 未与手工特征（~1.05）或模板句基线（~0.2–0.4）对比 → −3；
- 结论词与自身 CIDEr 明显矛盾 → −5；
- 附加分析质量高（BLEU/METEOR/ROUGE 全套、失败样例、注意力可视化）→ +3（封顶 60）。

注：冻结测试集为官方子集 200 图、训练仅 1,000 图（论文 1/9）；认真复现者预期 CIDEr 1.2–1.8（A≈35–58）；手工特征/弱模型 0.6–1.2（A≈10–35）。判分时参考「相对手工特征显著提升」这一论文核心结论。

## B. 证据真实性（25 分）

- 提交必须含可运行代码 + 证据表（含 model/lead_time/overall_mae 等列）——缺任一 → ≤10 分。
- 裁判抽查 2 个关键数，运行提交代码（或等价重算脚本）从冻结 CSV 重算：
  1. **数据事实**：冻结 CSV 行数 = 1,411（不含表头），日期 2020-10-16 → 2024-08-26，5 个目标站点列完整无缺失；
  2. **某模型某 lead time 的 Overall MAE**（如 NBEATS 或 DLinear 28 天）：从 agent 代码 + 固定种子重算，与证据表一致。
- 计分：
  - 两个抽查数均可重算且与报告一致 → 25。
  - 每个抽查数不可重算/不一致 → 各扣 8-12 分。
  - 无代码/代码不可运行 → 扣 8 分；evidence_table 缺失或列不完整 → 扣 5-10 分。
  - 报告把外部数字当实测（抄数，如直接引用官方 xlsx）→ B 直接 ≤10 分。

## 判定流程（judge 步骤）

1. 读 `TASK.md` → 确认提交物齐全（代码 + evidence_table.csv + report.md）。
2. 按 A1/A2/A3/A4 判定（必要时从 report 与 evidence_table 核对分 lead time 分解）。
3. 从冻结数据重算抽查 2 数 → 打 B。
4. 依 C1-C3 打 C。
5. 总分 = A+B+C；将得分与理由写入评测报告。

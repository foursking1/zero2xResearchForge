## A. 核心结果达成度（60）

锚：ResU-Net F1 = **71.65%**（论文 Table I；定义口径见 PAPER_ANCHOR.md）。取 agent 证据表中的整体 F1（landslide 类，阈值须报告）。

相对差 `d = |F1_agent − 71.65| / 71.65`：

| d | 得分 |
|---|---|
| d ≤ 10% | 48–60（越接近 71.65 越高；d≤5% 给 55–60） |
| 10% < d ≤ 30% | 30–47 |
| 30% < d ≤ 50% | 12–29 |
| d > 50% 或未报告 F1/阈值 | 0–11 |

扣分/加分项（在区间内调整）：
- 未报告 Precision/Recall 或阈值 → −5；
- 未与平凡基线（全 0）对比 → −3；
- 结论词（supported/partially_supported/contradicted/inconclusive）与自身 F1 明显矛盾 → −5；
- 附加分析质量高（阈值敏感性曲线、类别不平衡讨论、模态消融）→ +3（封顶 60）。

## B. 证据真实性（25）

- 提交含可重跑代码 + `evidence_table.csv`（含 TP/FP/TN/FN）→ 8 分（缺任一 → 0–4）。
- 裁判抽查（25 分中占 17 分，按下列 2 项）：
  1. **整体 F1 重算**：裁判在干净环境运行提交代码（或直接按代码逻辑）从 `data/test/` 冻结数据重算整体 F1、Precision、Recall；与 agent 报告值一致（≤0.5pp 容差）→ 9 分；不一致 → 0–4（若数字疑似直接抄论文 71.65% 而非从冻结数据算出 → 0）。
  2. **测试集 base rate 重算**：从冻结测试掩码统计滑坡像素占比，与 agent 报告的 base_rate 一致（≤0.1pp）→ 8 分；不一致 → 0–4。
- 任一抽查数字无法从冻结数据 + 代码重建 → B 整项 ≤ 10。

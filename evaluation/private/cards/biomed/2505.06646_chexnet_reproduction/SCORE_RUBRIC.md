# 裁判 Rubric：2505.06646_chexnet_reproduction（L2，总分 100）

## 判分模型
- 判分模型：Claude / GLM 等 LLM 裁判均可；证据重算由裁判运行提交代码完成。
- 判分输入：`claim.md`、`code/`、`results/`、`report.md` + 冻结数据 `data/`。

## A. 核心结果达成度（60 分）

| 锚 | 论文值（出处，私有） | 判分规则 |
|---|---|---|
| A1 复现版平均测试 AUC | 0.79（论文 CheXNet 复现模型，Results） | 提交复现版平均 AUC 与 0.79 相对差 ≤10% → 满分；≤25% → 半满；>25% → 低分 |
| A2 增强版平均测试 AUC | 0.85（论文 DACNet，Results） | 提交增强版平均 AUC 与 0.85 相对差 ≤10% → 满分；≤25% → 半满；未实现增强 → 参照 A1 判定 |
| A3 平均 F1 的量级模式 | 复现版 ~0.08；增强版 ~0.39（论文 Results） | 提交平均 F1 落在论文值的 ±0.15 绝对差内 → 满分；±0.25 → 半满；报告 F1 但量级明显不符（如 >0.6）→ 低分（说明阈值/评估口径） |

- 档位折算：每锚 20 分；满分 20 / 半满 10 / 低分 0-5；A 总分上限 60。

## B. 证据真实性（25 分）

- 提交必须包含 `code/` 与 `results/`；缺失 → B 直接 0。
- 裁判抽查 1-2 个关键数：
  1. **抽查字段 1**：`results/evidence_table.csv` 中任一模型（如增强版）的 `mean_auc`。
  2. **抽查字段 2**：`results/metrics.json` 中 Pneumonia（或任一稀有类）的 F1。
- 裁判从冻结数据运行提交代码（或独立复核脚本）重算：
  - 能重算且一致 → 满分 25；
  - 有 1 个不一致（AUC 相对差 >2%）→ 12-20；
  - 无法重算/无代码/抄论文数字 → 0-10。

## C. 方法与报告（15 分）

- C1（5 分）方法合理：DenseNet-121 复现、多标签损失、阈值策略与论文对齐程度。
- C2（5 分）防泄漏：测试分片未参与训练/调参；划分清晰。
- C3（5 分）报告：`report.md` 含方法、结果、局限（冻结子集规模、训练资源、与全量数据差异）与结论标签。

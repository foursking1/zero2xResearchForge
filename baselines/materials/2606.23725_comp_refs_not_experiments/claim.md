# claim.md — 可证伪声称、失败条件与结论标签

## 可证伪声称（一句话）

**H0**：GNN 电压筛选器在未见过的 Na-ion 阴极上的预测误差小到足以驱动材料筛选决策（≤ 0.30 V 筛选级），且其训练/评估所用的计算参考电压（Materials Project PBE+U 平均电压）≈ 实验电压，故一个常数（加性）偏移即可校准该系统对实验电压的系统误差。

> 该声称将"可筛选"与"参考≈实验 + 加性可校准"绑定为一整条假设链；任何一环不成立即推翻 H0 的对应部分。

## 失败条件（何种证据会推翻它）

以下任一条件成立即可推翻/削弱 H0：

1. **误差超出筛选级阈值**：规范口径（tier A/B，n=6）下，筛选器相对实验电压的 MAE ≥ 0.30 V（筛选级上界）。若 MAE ≥ 0.50 V，则连"排序级"都够不上（预注册梯子：<0.30 筛选级 / 0.30–0.50 排序级 / >0.50 不可用于筛选）。
2. **残差非"常数偏移"结构**：若残差（signed error）与实验电压存在强线性相关（|Pearson r| 大），说明误差是电压依赖的而非常数——常数偏移校准在结构上不可能成立。
3. **加性校准样本外失效**：用留一法（估计偏移的行与评估的行不重叠）做常数偏移校正后，校正后 MAE 不显著低于原始 MAE（甚至更高），且保守 95% 置信上界仍 >0.50 V。
4. **计算参考 ≠ 实验**：在预测/计算参考/实验三方齐备的行上，`v_mp − v_lit` 的系统偏差 |均值| 达到亚伏级（≈0.5 V 量级），说明"用计算参考训练/评估的筛选器对实验也有用"的前提不成立。
5. **自有基准不可信**（次级）：本地 PBE+U 基准相对实验平台的偏移 δ 的样本标准差 ≥ 0.30 V，即该基准不能作为绝对电压的可信来源。

## 结论标签

**`contradicted`**（在验证集边界内；因 n=6/7 < 20，触发预注册 provisional 限定，见 `report.md`）。

- H0 被明确推翻：原始 MAE = 0.668 V（规范 n=6，不可用于筛选）；残差-电压 Pearson r = −0.939（强电压依赖）；留一偏差校正后 MAE 反升到 0.802 V，bootstrap 95% 保守上界 ≈ 1.09 V；三方分解显示误差主源是计算参考（MP PBE+U）相对实验低约 0.54 V，而非模型自身。
- 边界声明：本结论只适用于本验证集（7 个 Na-ion 阴极、三种化学家族、tier A/B 为主），不构成对"所有 ML 材料筛选"的普适否定。
- 若只按"无法在绝对意义上证明 H0"的弱口径看，也可记为 `partially_supported`（仅限 provisional 标签）；但就"筛选器可用 + 加性校准有效"这一强声称而言，证据方向一致指向 `contradicted`。

# claim.md — 结论判定（TJH 早期死亡预测）

任务：`2209.07805_covid_ehr_bench`
论文：A Comprehensive Benchmark for COVID-19 Predictive Modeling Using Electronic Health Records in Intensive Care, arXiv:2209.07805

> 判定口径：所有指标均由本包 `code/` 中的代码在冻结数据上运行得到（固定种子），
> 论文数值仅作对照（见 PAPER_ANCHOR.md）。统计细节见 `results/metrics.json`，
> 每个模型的逐患者得分为 `results/predictions.csv`。

## 总体结论：`partially_supported`

- 论断 1「ICU 早期死亡预测可达很高判别力」：**支持**（量级上复现）。
- 论断 2「时间感知损失（TA）带来一致且显著的提升」：**未复现**（差异不显著）。

## 三问分别判定

### Q1. 数据装配

| 项 | 数值 | 与论文口径关系 |
|---|---|---|
| 训练集 | 375 例（文件发布口径）；**361 例可用**（14 例仅有空占位行，无任何测量/时间戳，已剔除并报告） | 论文 Table 1: 375 train（TJH 485 = 375+110） |
| 测试集 | **110 例（冻结测试集，与论文一致）** | 论文 Table 1 | 
| 行数 / 时间步 | train 6,106 行，median 16 步/例（72h 窗内 8 步）；test 757 行，median 5 步/例（72h 窗内 2 步） | 时序 EHR 口径 |
| 特征数 | 训练文件 74 项实验室/生命体征 + 年龄/性别；**冻结测试文件仅含 3 项共享特征（LDH、hsCRP、淋巴细胞%）** | 论文 74 特征；测试集为子集口径（最大差异点） |
| 院内死亡 | train 174/375=46.4% 死亡；test 13/110=11.8% 死亡 | 分布偏移显著（论文未给出测试死亡率） |
| 缺失率（72h 窗，患者级） | train: LDH 3.1%、hsCRP 4.4%、淋巴 1.9%；test: 0.0%–0.9%；行级 3 特征缺失约 85%（每行通常只带 1–2 项化验） | 论文开放管线已预处理；本复现用训练集统计量插补 |

### Q2. 早期死亡预测复现（冻结测试集，AUROC/AUPRC ×100）

| 模型 | AUROC | AUPRC | 论文锚对照 |
|---|---|---|---|
| RandomForest（ML 基线） | **96.35** | 85.54 | 论文 RF 96.58±2.20 |
| LightGBM（ML 基线） | **96.75** | 86.42 | —— |
| Logistic（clinical 式，3 项化验） | **96.67** | 85.47 | 4C 94.16±2.57（4C 无法重建：测试集无年龄/呼吸/尿素/GCS） |
| GRU（时序模型） | **96.56±0.15**（5 seeds） | 86.74±0.34 | —— |
| GRU-TA（时序+时间感知损失） | **96.64±0.12**（5 seeds） | 86.77±0.42 | 论文 GRU-TA 97.70±2.06 / 96.50±3.04 |

- 结论：时序模型（GRU）AUROC **96.56**，ML 基线 AUROC 均 **≥96** —— 均大幅超过论文量级判定的满分线（时序 ≥90、基线 ≥85）；与论文 RF 96.58 几乎重合、与论文 GRU-TA 97.70 相差约 1.1 个百分点。
- 上述结果仅使用 3/74 项特征；在论文完整 74 特征口径下预期判别力至少不低，故定性论断（高判别力）成立。

### Q3. 时间感知损失（TA）验证

- GRU-TA 96.64 vs GRU 96.56：ΔAUROC = **+0.08** 个百分点（5 seeds 配对 Wilcoxon p = **0.25**，不显著）。
- 判定：在本冻结数据「3 特征子集 + 120 例小样本」口径下，**未观察到论文所述"TA 显著提升"**；方向与论文一致但幅度可忽略、无统计显著性。视为**未复现**（受数据子集与样本量限制，不能据此否定论文原口径结论）。

## 关键数字（供裁判抽查）

- `results/evidence_table.csv`：时序模型 `gru` auroc=0.96558 (96.56)；最优 ML `lightgbm` auroc=0.96749 (96.75)。
- `results/metrics.json`：`testing_set_size_patients` = **110**，`test_positives` = 13；`conclusion.label` = `partially_supported`。

## 局限（影响外推的要点）

1. 冻结测试集仅有 3/74 项实验室特征（LDH/hsCRP/淋巴细胞%），全部模型/插补在该子集口径下评测；年龄、性别、其余 71 项特征在测试文件中缺失。
2. 单中心 TJH；CDSL（HM Hospitales）4,479 例不在本数据包内。
3. 4C 临床评分无法重现（缺 age/RR/SpO2/urea/GCS）→ 用 3 项化验的 logistic 作"临床式"基线近似。
4. 训练/测试死亡分布漂移（46.4% → 11.8%），AUPRC 受先验影响，与论文不同口径，不可直接比较 AUPRC 绝对值。
5. TA 损失为本复现对论文方法的近似实现（线性时间衰减加权）；与 pyehr 的原始 TA 损失可能有实现差异。

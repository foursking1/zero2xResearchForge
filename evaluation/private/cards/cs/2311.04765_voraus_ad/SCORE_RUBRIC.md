## B. 证据真实性（25 分）

- 提交必须含可运行代码 + 证据表（含 category_id/n_anomaly/auroc_main/基线列）——缺任一 → ≤10 分。
- 裁判抽查 2 个关键数，运行提交代码（或等价重算脚本）从冻结 parquet 重算：
  1. **数据事实**：sample 数 = 2,122；`setting==72` 样本数 = 948；`category==5`（miss_can）n_anomaly = 72（与表 VI 样本基数一致）；
  2. **某类别 AUROC 或平均 AUROC**：从 agent 代码 + 固定种子重算，与证据表一致。
- 计分：
  - 两个抽查数均可重算且与报告一致 → 25。
  - 每个抽查数不可重算/不一致 → 各扣 8-12 分。
  - 无代码/代码不可运行 → 扣 8 分；evidence_table 缺失或列不完整 → 扣 5-10 分。
  - 报告把外部数字当实测（抄数）→ B 直接 ≤10 分。

- 明显泄漏（用测试样本训练/调参/校准）→ C 总分 ≤5，且 B 中该数不可信。

## 判定流程（judge 步骤）

1. 读 `TASK.md` → 确认提交物齐全（代码 + evidence_table.csv + report.md）。
2. 按 A1/A2/A3 判定（必要时从 report 与 evidence_table 核对逐类别分解）。
3. 从冻结数据重算抽查 2 数 → 打 B。
4. 依 C1-C3 打 C。
5. 总分 = A+B+C；将得分与理由写入评测报告。

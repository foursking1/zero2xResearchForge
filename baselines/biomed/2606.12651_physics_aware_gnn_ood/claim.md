# claim.md — L1 关键论断判定

**论文**：Physics-Aware GNN for Out-of-Distribution Molecular Property Prediction（arXiv:2606.12651）
**任务**：`2606.12651_physics_aware_gnn_ood`
**数据**：冻结包 `data/`（HIV 41,127 + Tox21 7,831 + COCONUT_30k_seed42 30,000）

## 三问判定

### Q1. 基线复现（COCONUT 单源 OOD，ROC-AUC）
- 实测：**mean OOD AUC = 0.98521**（5 seed：0.98642 / 0.98431 / 0.98881 / 0.98374 / 0.98275）
- 论文基线：0.9774
- 相对差：**+0.80%**（≤5% 容差）→ **Supported（复现成功，且略优于论文基线）**

### Q2. 物理感知变体消融（同种子配对 Δ + 10,000 次 bootstrap 95% CI）
| 变体 | 论文 Δ（CI） | 实测 Δ（95% CI） | CI 不含 0 | 判定 |
|---|---|---|---|---|
| +complexity | +0.0060（[+0.0023, +0.0102]） | −0.00115（[−0.00547, +0.00376]） | 否（且方向为负） | 未复现 |
| +strain | +0.0032（[+0.0008, +0.0052]） | +0.00151（[−0.00132, +0.00444]） | 否 | 方向对，未达显著 |
| **+both** | **+0.0066（[+0.0038, +0.0093]）** | **+0.00243（[+0.00094, +0.00393]）** | **是** | **复现（组合最优）** |

→ 关键论断「至少一个物理感知变体显著提升且 CI 不含 0」**成立（+both 变体）**；但「三种变体均显著」仅部分成立。→ **Partially Supported**

### Q3. 标签分布（SAScore <4 easy / >5 hard，中间带 4–5 丢弃）
- 实测：语料 65,561 = 53,552 easy / 12,009 hard（**81.7 / 18.3**）
- 论文：65,177 = 53,159 easy / 12,018 hard（82 / 18）
- 相对差：easy 比例 |81.7−82|/82 ≈ **0.4%**（≤15% 容差）→ **Supported（冻结数据标签分布与论文口径一致）**

## 结论标签

**`partially_supported`**

- 基线 AUC、标签分布、以及「+both 组合变体显著提升 OOD、配对 CI 不含 0」均被实测复现；
- +complexity / +strain 单独在主要协议下未达到论文所述的显著性（+strain 方向为正但 CI 含 0，+complexity 约 −0.001 且 CI 含 0），敏感性协议（无类别加权、强 aux 权重 λ=0.5）下 +both 与 +complexity 甚至显著为负 → 论文"三种变体均显著提升"的更强表述未被稳定复现。

# report.md — 完整复现报告

## 0. 摘要

本报告复现 arXiv:2209.07805（ICU COVID-19 EHR 结局预测综合基准）在 TJH 队列上的**早期死亡预测**关键论断：在冻结的 375+110 训练/测试时序 EHR 上，实现 3 个 ML/临床式基线（RandomForest、LightGBM、Logistic）与 2 个时序模型（GRU、GRU-Time-Aware），在冻结测试集（110 例，13 死）上报告 AUROC/AUPRC，并与论文 Table 5 对照。

**结论标签：`partially_supported`**。核心量化结果：

- 时序模型 GRU AUROC **96.56±0.15**、GRU-TA AUROC **96.64±0.12**（5 seeds）；ML 基线 96.35–96.75 → 高判别力论断在量级上复现（论文 GRU-TA 97.70、RF 96.58）。
- TA 对比：ΔAUROC=+0.08，Wilcoxon p=0.25 → "TA 显著提升"未在本子集口径复现。

## 1. 背景与目标

论文提出两个 ICU 任务（结局特异性住院时长预测、早期死亡预测），以 18 个模型在两家真实 COVID-19 EHR 队列评测。本卡聚焦 TJH（同济医院）队列 Table 5 的两条核心论断：

1. 早期死亡预测可达很高判别力（GRU-TA AUROC 97.70±2.06 / AUPRC 96.50±3.04；4C 94.16±2.57）。
2. 时间感知损失（TA）使模型在多项指标上显著优于原模型（*，p<0.05）。

## 2. 数据与装配

### 2.1 数据源
- 冻结数据：`time_series_375_prerpocess_en.xlsx`（训练）与 `time_series_test_110_preprocess_en.xlsx`（测试），来自论文引用的公开 TJH 数据集（HAIRLAB/Pre_Surv_COVID_19），SHA-256 与 `data/README.md` 一致。
- 名录：CDSL（HM Hospitales 4,479 例）需申请，不在本包内；本卡仅评测 TJH。

### 2.2 数据形态
- 长格式：每行一次测量；PATIENT_ID 仅首行出现（前向填充恢复患者块）；`RE_DATE` 测量时间戳、`Admission time` 入院时刻、`outcome` 该患者二值院内结局（患者内一致，无误标）。
- **特征覆盖不对称（关键冻结口径）**：训练文件含 74 项实验室/生命体征 + 年龄/性别；**测试文件仅含 3 项共享特征：LDH、hsCRP、淋巴细胞%**。论文 Table 1 口径为 74 项特征。

### 2.3 统计量（与论文 Table 1/2 关系）

| 指标 | 训练 | 测试 |
|---|---|---|
| 患者数（发布） | 375 | 110 |
| 患者数（可建模） | 361（14 例纯空占位行剔除） | 110 |
| 测量行数 | 6,106 | 757 |
| 中位测量数/例（全疗程） | 16（mena 16.9，max 59） | 5（mean 6.9，max 37） |
| 中位测量数/例（前 72h） | 8 | 2 |
| 院内死亡 | 166/361=46.0%（174/375=46.4%） | 13/110=11.8% |
| 特征数（用于建模） | 3 共享 + (年龄用于描述) | 3 |
| 72h 窗患者级缺失率 | LDH 3.1% / hsCRP 4.4% / 淋巴 1.9% | 0.0–0.9% |

- 行级稀疏度：训练文件每行通常仅带 1–2 项化验，3 个共享特征的行级观测比约 15%（全 74 特征的行级缺测 >85%）；测试文件 3 特征行级观测比约 40–50%。
- 与论文口径的关系：样本数（375/110）与论文 Table 1 一致；时程与结局为数据实际字段定义；特征列按"冻结数据实际字段核对"（附录 A）。差异点：论文用 74 特征全量，冻结测试为 3 特征子集；训练/测试死亡率漂移明显（46.4%→11.8%），说明测试期入院人群更轻症（与数据发布的时间顺序一致）。

## 3. 方法

### 3.1 任务定义
- **结局**：院内死亡（`outcome`=1），患者级二值。
- **预测窗口**：入院后前 72h 的测量做早期预测（若某例在 72h 内无记录，则使用其最早一行，保证无患者丢失）。敏感性：48h、168h、全疗程。
- 排除（防泄漏）：结局仅在出院时已知；本任务用前 72h 数据预测最终结局，不使用出院后信息。

### 3.2 预处理
- 患者分块 → 按时间排序 → 前向填充。
- **Aggregate 表示（ML）**：每例每特征聚合 {last, first, mean, min, max, slope(线性拟合), n, sd, 末次时刻} + 临床比值（LDH×CRP、CRP/淋巴、LDH/淋巴）+ 缺失指示列（`__missing`）。未测患者用**训练集**中位数填充，再以训练集拟合的 StandardScaler 标准化。
- **Sequence 表示（GRU）**：72h 等分 12 个 6h bin，每 bin 取"观测到的最新值"+观测盒掩码（通道与值交替排列）；bin 间 LOCF，残余用**训练集**特征均值（掩码保持 0）。
- 插补/缩放统计量全部只由训练集拟合；测试集零参与（防泄漏）。

### 3.3 模型
1. **RandomForest**：600 棵树，max_features='sqrt'，全展开（聚合特征）。
2. **LightGBM**：800 树，lr=0.03，num_leaves=15。
3. **Clinical-style Logistic**：三项 `last` 化验值 + 缺失指示，C=1。作为无法重建的 4C 评分的替代基线（4C 需 age/RR/SpO2/urea/GCS，测试集无）。
4. **GRU**：1 层 GRU(48) + 逐步 linear 头；逐时间步 BCE；Adam(lr=1e-3, wd=1e-4)；80 epochs；训练集内 20% 验证（按患者）选最优 checkpooint。
5. **GRU-TA**：同架构，损失改为时间感知加权 —— 死亡患者预测步权重 `w_t = 1 + γ·(T−t)/T`（γ=1.0，越早越重），存活患者均匀；测试分数 = 各时间步概率均值池化（验证集上优于末步/最大池化）。
- GRU/GRU-TA 各 5 个种子，报告 mean±std；Moons 随机种子全固定。

### 3.4 评估
- AUROC / AUPRC（×100），sklearn；报告 mean±std（时序模型）；GRU vs GRU-TA 用逐 seed 配对 Wilcoxon 检验。

## 4. 结果

### 4.1 早期死亡预测判别力（冻结测试集 N=110，13 死）

| 模型 | 类型 | AUROC（×100） | AUPRC（×100） | 论文锚 |
|---|---|---|---|---|
| LightGBM | ML 基线 | **96.75** | 86.42 | – |
| 临床式 Logistic | clinical 基线 | **96.67** | 85.47 | 4C 94.16±2.57（口径不同） |
| RandomForest | ML 基线 | **96.35** | 85.54 | RF 96.58±2.20 |
| GRU | 时序 | **96.56 ± 0.15** | 86.74 ± 0.34 | – |
| GRU-TA | 时序+TA | **96.64 ± 0.12** | 86.77 ± 0.42 | 97.70±2.06 / 96.50±3.04 |

- 所有模型 AUROC ≥ 96，远超"≥90（时序）/≥85（基线）"满分档；与论文 RF 数值基本重合（96.35 vs 96.58），与 GRU-TA 差约 1.1 个百分点（仅用 3/74 特征的子集口径，合理且预期差异属保守侧）。
- 图：`evidence/figures/roc_pr_curves.png`（ROC/PR + 各模型 AUC）；`feature_importance.png`。
- 逐患者得分：`results/predictions.csv`。

### 4.2 TA 时间感知损失

| 对比 | AUROC | AUPRC |
|---|---|---|
| GRU（均值池化） | 96.56±0.15 | 86.74±0.34 |
| GRU-TA（γ=1.0） | 96.64±0.12 | 86.77±0.42 |
| Δ | **+0.08** | +0.03 |

- 5 seeds 配对 Wilcoxon 秩和：p = **0.25**（不显著）。
- 敏感分析（训练验证集、与测试无关）：γ∈{0.5,1,2} 与池化方式 {last,max,mean} 下差异均 <0.2 个百分点 → 结论稳健。
- **判定**：方向与论文一致（TA 略优），但在本数据（3 特征子集、120 例测试、13 阳性）下无统计显著性，论文"TA 显著提升（p<0.05）"未能在本口径复现。此结论受限于子集特征量与样例量，不能推广到论文全特征 74 维口径。

### 4.3 时间窗敏感分析（任务设计对比，全疗程 vs 早期窗）

| 预测窗口 | RF bin-level AUROC | RF AUPRC | GRU AUROC |
|---|---|---|---|
| 48h | 0.9596 | 0.8347 | 0.9580 |
| 72h（主设定） | 0.9508 | 0.7679 | 0.9663 |
| 168h（7 天） | 0.9929 | 0.9583 | 0.9869 |

- 随窗口放宽容纳更多测量，判别力上升（168h≈0.99），说明"越早越难、数据越少"的损耗符合直觉；主设定 72h 兼顾"早期"语义与稳健性。

### 4.4 特征重要性与校准检查
- 顶特征（Gini）：以三项化验的 `last`/`mean`/`max` 为主（LDH、hsCRP、淋巴%），与单变量点二列相关（|r|≈0.59–0.68）一致；详见 `results/feature_importance_top25.csv`。这些正是 COVID 严重程度经典三联标记，解释了 3 特征即达高判别力。

## 5. 结论

- **论断 1（高判别力）**：✅ 支持。时序模型 96.56–96.64、ML/基线 ≥96，全部达到论文量级（RF 96.58 / GRU-TA 97.70 同一水平），且仅用 3/74 特征。
- **论断 2（TA 显著提升）**：❌ 未复现（Δ=+0.08，p=0.25）。
- **总标签：`partially_supported`**（claim.md）。

## 6. 局限与威胁因素

1. **子集口径**：冻结测试集仅 3/74 特征，与论文/开放管线的 74 特征评测不同（pyehr 用全部 74 项 + 年龄性别）；本复现不得不在共享特征子集上评测，无法验证论文"全特征增益"。
2. **样本与分布**：测试 13 阳性，AUROC 置信区间宽 ~±3-4 个百分点（本卡也以该宽内容许做量级档；AUPRC 对剔除先验敏感）；训练(46.4%)与测试(11.8%)死亡率漂移。
3. **4C 未能重建**：测试文件缺 age/RR/SpO2/urea/GCS，临床评分基线以 3 化验 logistic 替代（方向性对照，非论文 4C）。
4. **TA 为近似实现**：本复现的 TA 加权（线性时间衰减，γ=1）为论文"time-aware loss"的合理近似，与 yhzhu99/pyehr 原实现可能有差异。
5. 单中心 TJH；CDSL 未含；缺失插补策略（LOCF+训练均值/中位数）与 pyehr 管线不同。
6. 所有模型在训练集上未刻意调超参（默认+轻量设定），意在报"冻结数据上的公平复现"而非"调参上限"。

# SciSolveBench 评测体系 v7 总结报告

> 仅改评测（judge），**未改动任何 agent 交付物**。任务无需重跑。

## 一、v7 改了什么（针对你的两个质疑）

| 维度 | v6（旧） | v7（新） |
|---|---|---|
| B 维度定义 | "证据齐全**自洽**"（agent 内部不矛盾即可） | "与**论文真值一致性 / 可验证性**" |
| 真值来源 | judge 不读 `PAPER_ANCHOR.md` 真值 | judge 强制读取任务目录已有 `PAPER_ANCHOR.md`，拿 agent 的 `metrics.json`/`claim.md` 数值逐项比对 |
| truth_check | 无 | 新增 `matched / diverged / unverified / empty`，代码强制钳制 B 上限（空壳≤10 / 不可验证≤15 / 偏离≤25 / 匹配≤40） |
| A1 交付 | 交付即满分 | 要求机器可读证据，仅散文则封顶 |
| L1/L2 口径 | 含 L3 | 去掉 L3，仅 L1（论文复现）/L2（多步骤+legacy） |

关键：每个任务目录**本来就存在 `PAPER_ANCHOR.md`（论文真值）**，v6 的 judge 只是没去用它。v7 让 judge 真正做了"实测 vs 真值"比对，无需新增交付物。

## 1. Input（输入：冻结真实数据）

数据包位于 `data/`，全部为**真实观测数据**（NOAA GOES X 射线耀斑事件的官方衍生标签，HuggingFace 官方仓库冻结，CC-BY-4.0），详见 `data/SOURCE.md`（来源、许可、逐文件 SHA-256、与官方源逐字节核对记录）。

数据由 **NASA-IBM AI4Science SuryaBench 项目**的"全盘太阳耀斑预测"应用数据集（论文中记作 DS4）提供：以 **1 小时为步长**滚动生成 **24 小时预测窗口**，覆盖 **2010-05-13 00:00 → 2024-12-31 23:00**（太阳活动周 24 全程 + 活动周 25 上升期）。每个窗口的标签由窗口内发生的 ≥C 级 GOES 耀斑事件派生。**不含 SDO 影像**——本包只有 GOES 派生标签序列（标量数据）。

### 1.1 文件清单

| 文件 | 内容 | 行数（数据行） |
|---|---|---|
| `data/train.csv` | 官方训练划分：2010–2019 每年 2/15–12/31（2010 自 5/13 起） | 74,760 |
| `data/validation.csv` | 官方验证划分：2010–2019 每年 1/15–1/31 | 3,672 |
| `data/test.csv` | 官方测试划分：2020–2024 全部小时（太阳活动周 25 上升期，**模型未见**） | 43,848 |
| `data/leaky_validation.csv` | 官方"泄漏验证"划分：2011–2019 每年 1/1–1/14 与 2/1–2/14（紧邻训练期） | 6,048 |
| `data/data.csv` | 全量记录 2010-05-13 → 2024-12-31（= 上四文件之和，逐行一致） | 128,328 |

### 1.2 字段 Schema（所有文件一致）

| 列 | 含义 |
|---|---|
| `timestamp` | 24h 预测窗口的**开始时刻**（本地时区，小时步长） |
| `max_goes_class` | 窗口内最大强度耀斑的 GOES 级别（如 `C5.2`、`M1.0`、`X3.2`）；窗口内无 ≥C 级耀斑时为 `FQ` |
| `cumulative_index` | 窗口内所有 ≥C 级耀斑的加权累积指数：C 级 ×1、M 级 ×10、X 级 ×100（对子类数值加权求和，如 M2.0 计 20、X3.5 计 350） |
| `label_max` | **本任务目标**：窗口内最大耀斑 ≥ M1.0 记 1，否则 0 |
| `label_cum` | 窗口内累积指数 ≥ 10 记 1，否则 0 |

已知口径：`label_max = 1 ⟺ max_goes_class ≥ M1.0`、`label_cum = 1 ⟺ cumulative_index ≥ 10`，二者可从原始两列 100% 重算一致（已核对）。数据规模官方口径：论文正文报告 DS4 共 128,352 个标签；官方 HuggingFace README 与冻结全量 `data.csv` 均为 128,328 行，差 24 行（1 天），属论文计数与发布文件间的已知差异，不影响本任务（以冻结文件为准）。

### 科学目标（Scientific goal）

端到端复现并评估目标论文提出的方法（目标论文不提供，冻结数据即全部输入）：

> **核心论断**：ML 模型能基于历史观测预测未来 24h 窗口内是否发生 ≥M1.0 耀斑（正技能），且该技能在**未见时段（跨太阳活动周，2020–2024 活动周 25 上升期）**上保持——即"模型学到可泛化的预报信号，而非记忆训练周期"。

请基于冻结数据回答：

1. **数据与口径**：全量/各 split 的样本量与正类率（`label_max`）各是多少？`label_max`/`label_cum` 与原始两列是否自洽？训练期（2010–2019）与 test 期（2020–2024）的正类率漂移多少？
2. **核心结果**：在官方 test 期上，你的模型对 `label_max` 的 TSS、HSS 是多少？TSS = TPR − FPR 是否显著为正（正技能，而非碰运气）？
3. **泛化归因**：test 期技能是"真实可泛化信号"还是"正类率漂移的有利假象"？用分年/分活动水平数据论证（例如 2020 太阳极小 vs 2023–2024 活动峰值）。
4. **防泄漏**：所有特征是否**严格滞后**于窗口开始时刻？warm-up 缺失如何处理并报告？结论对决策阈值是否稳健（阈值敏感性/不确定性区间）？
5. **结论**：给出四档结论标签与适用边界（适用时段、输入口径、类别不平衡处理、不宣称的内容）。

提示（不给方法步骤）：以冻结数据为准；类别不平衡是核心难点；把"整体技能"与"漂移带来的技能"分开讲；TSS 对阈值与基率都敏感，报告时不只给一个数；`max_goes_class`/`cumulative_index` 描述的是**被预测窗口本身**，绝不能当特征。

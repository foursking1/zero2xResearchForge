## 判分对照速查（judge 用）

- A1 满分：至少一个 N 档上 imbalanced top-1 < balanced top-1 且 Δ ≥ 1.0pp；教师/压缩管线/子集协议在报告中明确。
- A2 满分：≥2 个 N 档均方向一致（全部 imbalanced < balanced），且至少一个 Δ ≥ 1.0pp。
- B 抽查两数：(1) CIFAR-10 训练每类 5,000 / 测试每类 1,000（纯数据事实，从冻结 pickle 解码核验）；(2) agent 报告的平衡/不平衡子集逐类样本量是否符合其声明的协议（从冻结数据重算）。
- 容差说明：论文未开源代码，且教师/子集抽样/压缩超参口径不完整；本包 CIFAR-10 顺序与官方 tar 可能有差异 → 判分以**方向 + 量级带**为主，不要求逐值复现（Δ≥1.0pp 即算显著，论文 Δ 范围 0.35–5.26）。

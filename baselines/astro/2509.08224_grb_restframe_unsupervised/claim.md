## 与论文逐项对比及差异归因

1. **目录规模与计数**：总行 320，Type I = 45、Type II = 275，与 M20 ReadMe "45 type I and
   275 type II" 完全一致。论文 §2.2 称 M20 共 314、取 300（剔除 14 个红移不准），其中
   剔除名单不在冻结包内；本卡以 M20 全表 320 为口径（与 ReadMe/编译器一致）。
2. **人口占比**：M20 Type I 14.06% vs 论文 GRBs-I 14.32–14.59%。差值 0.26–0.53 pt 归因于
   两个因素：(a) 样本组成不同——论文为 300 个 M20（剔除 14 个）+ 70 个新 GRB = 370，
   本卡为 320 个全表 M20；(b) 分族方式不同——论文是 t-SNE/UMAP 嵌入后的聚类归属，
   ~14% GRBs-I 与 M20 目录 Type I 标签并非一一对应（如 110402A 两方法归属不一致）。
   方向与量级完全一致，"~14% 小族"论断在目录层面成立。
3. **参数中位数**：T90z（0.27 vs 0.31 s）、Eiso（0.69 vs 0.28；100.0 vs 75.19）同量级一致；
   Epz 方向一致（两族 Type I 均高于 Type II：706 vs 446 keV，论文 523.83 vs 407.94 keV），
   Type I 的 Epz 存在 ~35% 绝对差，归因于 70 个新 GRB 进入论文 GRBs-I 组 + t-SNE 分组与
   目录 Type 标签的差异（目录 Type I 多含 110402A 等 Epz 极高、Eiso 偏高的 EE 事件）。
   结论为"分离显著"不受影响：T90z 相差 ~54 倍、Eiso 相差 ~145 倍。
4. **双峰结构**：64 个 T90z<2 s（20.0%）。Type I 中 93.3% 为短暴，但 Type II 中也有 22 个
   短暴（8.0%），即存在"短 T90 但非 Type I"的 GRB（含仅按 T90 无法与 SGRB 区分的
   低 T90 Type II），且 060614A（Type I+EE）的 T90z=4.4 s 属"长持续时间短暴"。
   直接支持论文"仅靠 T90 分类不可靠"的动机。
5. **特定事件交叉验证**：GRB 060614A = I+EE → 对应论文 GRBs-I（合并起源）；GRB 980425B、
   171205A = II+SNsp → 对应论文 GRBs-II（SN 关联）；GRB 110402A = I+EE，T90z=2.8 s、
   Epz=1924 keV、Eiso=15.2 → 边界案例，与论文"110402A 两方法不一致"一致；
   GRB 200826A（2020 事件，论文新样本）不在 M20 冻结目录中，如实报告。
6. **辅助交叉验证（M20 自身的 EH/EHD 分类）**：目录中 EHDtype 与 Type 一致率 99.1%、
   EHtype 与 Type 一致率 95.9%；Type I 中 80.0% 满足 EH>3.3、Type II 中 98.5% 满足 EH<3.3，
   说明"rest-frame 参数可无监督区分两族"并非仅依赖某一方法，进一步支持结论。
7. **诚实披露的补充实验**：在 320 样本上对 log10 标准化(T90z, Epz, Eiso) 做 k-means(k=2)
   作为健全性检查，得小簇 102（31.9%）——与论文 ~14% 不一致，这正是论文方法（370 样本 +
   t-SNE/UMAP 流形聚类）不可在 M20 单样本上复现的体现；已如实报告并归因，不作为判定依据。

## 判定理由（一句话）

M20 目录层面 Type I/II = 45/275（14.06%/85.94%）与论文 GRBs-I/II 占比 14.32–14.59% 一致，
两族 T90z/Eiso 中位数分离显著、短暴与 SN 关联事件归属均与论文一致 → 冻结数据口径下
**论断成立（supported）**；唯一未覆盖的是 370 样本嵌入的逐点重算（冻结包外）。

- 单位：Eiso 表值单位 10⁴⁴ J = ×10⁵¹ erg，数值即进论文的 ×10⁵¹ erg 口径；T90i/Epi 即为

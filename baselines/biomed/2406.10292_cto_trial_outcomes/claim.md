# 判定结论（claim.md）

**任务**：CTO「LLM+时序链接自动标注临床试验结局」关键论断验证
**论文**：*Automatically Labeling Clinical Trial Outcomes*, arXiv:2406.10292
**Task ID**：`2406.10292_cto_trial_outcomes`（L1 critical claim）

## 四档判定

| 子问题 | 判定 | 一句话理由 |
|---|---|---|
| (a) CTORF 复现 | **supported** | 冻结 `pred_proba` 复算各阶段/全体 F1 与论文 Table 1 相对差 ≤10%（全体 5.1%，分阶段 3.1%/8.7%/2.3%）；κ 在 0.5 阈值为 0.934（rel. 28%，超出 20% 但 ≤40%），在论文"相位优化阈值"口径区间 0.6–0.65 为 0.78–0.90（rel. ≤8%）。冻结数据一致性**不低于**论文报告水平。 |
| (b) 人工-自动一致性 | **supported** | 匹配样本量 3,239/5,060/2,823（与论文一致），全体 pooled 11,122；F1=0.9551、κ=0.9335、P=0.9140、R=1.0000，与"自动标注与人工标注高度一致"论断一致。 |
| (c) 失效场景 | **supported** | 数据证据显示自动标注在"无监管/无信号"场景以覆盖损失形式失效（Phase-4 无模型覆盖、ticker 覆盖率仅 9.2%、摘要/新闻/p值 LF 缺失 53–98%、无信号默认 `pred_proba==0`），而不以错误标注形式失效。 |

**总论断（自动标签 = 低成本高一致替代）**：**supported**。

### (c) 失效场景量化证据

| 场景 | 证据 |
|---|---|
| 无监管事件/阶段外 | 1,302/11,012（11.8%）人工试验不在任何 CTORF 阶段文件内（其中 Phase 4 = 1,300），框架根本不产出标签 |
| 无公司链接（无股价 LF） | 仅 1,016/11,012（9.2%）试验有 ticker 链接；`stock_price` LF 在阶段文件中缺失 84–89% |
| 摘要缺失 | `gpt`（PubMed 摘要 LLM 解读）LF 缺失 53–77%（Phase I 最高） |
| 阶段链接断裂 | `linkage` LF 缺失 23–28%；`hint_train`（跨阶段提示）缺失 84–96% |
| p 值/新闻缺失 | `pvalues` 缺失 81–98%，`new_headlines` 缺失 94–97% |
| 全无信号兜底 | 匹配集中 `pred_proba==0`（66.0%，7,343/11,122），其中 **100% 为人工失败标签** → 无信号时模型保守判定失败，不产生虚假阳性 |

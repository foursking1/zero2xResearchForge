## 校准杠杆说明（若实测偏离区间时调整）
1. **匹配口径杠杆**：本卡将匹配判定固化为「大类归并（Ia/II/Ibc），? 归入大类，Ic-broad 单列」——若评测时发现该口径导致普遍误判（如 SNIa? 类 DASH 常判 SNII），则调整口径表述或放宽 A2 阈值，而非放宽锚。
2. **A2 阈值杠杆**：主张成立判据（总体 ≥0.80、Ia ≥0.90）基于论文 Table 1（98.4%/89.3%）与冻结子集构成（Ia 占比 68%）外推；若评测显示子集真实匹配率系统性低于该区间，说明锚区间设定偏差，应下调阈值至子集合理值并记录。
3. **B2 抽查杠杆**：抽查对象（DES16C3bq/DES16E2aoh）选择依据是它们在 Table 2 中有明确记录且概率高（≥0.86）；若 v06 模型与论文模型差异导致子类型级失配率偏高，将判分依据放宽为「同大类」并注明。
4. **速度杠杆**：速度受机器影响大，A3 只要求报告实际耗时与可迁移性讨论，不做硬性阈值。
5. **环境杠杆**：astrodash 依赖 TF1（旧 checkpoint），若评测环境无法安装 TF1，视为环境问题而非数据问题：允许代理用 tf.compat 或 TF1.15 容器运行；仍失败则本卡标记为「评测环境阻塞」并在进度表记录，不修改锚。

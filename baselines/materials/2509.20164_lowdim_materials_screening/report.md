# 复现报告：2509.20164_lowdim_materials_screening

论文：Bagheri et al., *Massive Discovery of Low-Dimensional Materials from Universal Computational Strategy*, arXiv:2509.20164 (2026), Chem. Mater. 2026, DOI 10.1021/acs.chemmater.5c03151.
数据来源：Zenodo 10.5281/zenodo.17035156（`databases.zip`）。本报告所有数字均由冻结数据实际运行计算得到；论文数值仅用于对照讨论。

---

## 1. 数据与方法

### 1.1 冻结数据与完整性

| 文件 | 大小 | SHA-256（实测） | 清单值 | 一致 |
|---|---|---|---|---|
| `screened_materials.json` | 196,950,407 B | `A2240F0...FE88` | 同左 | ✓ |
| `2D_materials.json` | 13,209,708 B | `529694B0...0E1D` | 同左 | ✓ |
| `README.txt` | 3,233 B | `D595AAA6...3AD` | 同左 | ✓ |

### 1.2 文件格式与解析策略

两个 JSON 均为 **ASE 数据库导出格式**：顶层是 `"1","2",…,"ids","nextid"` 的字典；每条材料是一个序列化的 ASE `Atoms` 对象，性质字段位于 `key_value_pairs` 中（README 列出的 `mpid / dimen_larsen / fcdimen_score / dim_fcdimen_c1/c2/c3 / stable / ehull / mp_gap / …`；2D 文件另有 `E_exf / c2db / matpedia / mc2d / rae / topo / DBBs / robocrys`）。

- `screened_materials.json`（~197 MB）：用 `ijson` **流式**解析，仅抽取 `key_value_pairs` 标量字段，避免整文件物化；CPU 完成。
- `2D_materials.json`（~13 MB）：`json.load` 全量加载。
- `dimen_larsen` 与 `fcdimen_score` 是字符串化的 Python 字典（如 `"{'3D': 0.82, '01D': 0.15}"`），用 `ast.literal_eval` 解析；`"None"` 字符串表示无有效分数。
- 固定种子 42（本分析为确定性统计，无随机采样，种子仅作审计记录）；设备：CPU。

### 1.3 维度判据口径

FCDimen 三个变体标签直接取自 `dim_fcdimen_c1/c2/c3`。论文头条分布（9,139 = 0D 1,838 / 1D 1,760 / 2D 3,057 / 混合 2,484）对应 **c2（方法 ii）**：
- 纯维度：`0D / 1D / 2D / 3D`；
- 混合维度：`01D / 02D / 03D / 12D / 13D / 23D / 012D / 013D / 023D`；
- `"None"`：无有效分类（对应不稳定材料，见 §2.2）。

剥离能判据采用论文阈值（E_exf，单位按论文口径 meV/Å²）：易剥离 ≤35、可能剥离 35–125、强结合 ≥125。

### 1.4 已知 2D 数据库标记

`c2db / matpedia / mc2d / rae / topo / DBBs / robocrys` 布尔标记。任一为 `True` 视为「已在已知 2D 数据库/来源中出现」；全部为 `False` 视为「库外新材料」。

## 2. 结果

### 2.1 数据统计

**`screened_materials.json`（冻结文件实测）**
- 总条目：**35,689**
- 动力稳定（`stable=True`）：**24,515**；不稳定：11,174
- 有效 FCDimen 分类（c1/c2/c3 非 `None`）：**24,515**；`fcdimen_score = None`：11,174
  - 即不稳定 ⇔ 无 FCDimen 分数 ⇔ 标签为 `None`，三者完全一致。
- 全部 35,689 条 `dimen_larsen` 主维度 = `3D`（含全部低维材料）——与论文「筛选剔除 Larsen 已识别低维材料」一致。

**`2D_materials.json`（冻结文件实测）**
- 总条目：**2,988**；唯一 mpid：2,988；全部 `stable=True`；全部 `dim_fcdimen_c2 = '2D'`。
- `dim_fcdimen_c1` 分布：`2D=221, 3D=2576, 02D=115, 0D=37, 01D=37, 23D=2`（即 c2 是比 c1 更敏感的判据）。
- `dim_fcdimen_c3` 分布：`0D=924, 3D=1238, 02D=470, 01D=227, 2D=114, 012D=15`。

### 2.2 FCDimen 维度分布（核心）

`screened_materials.json` 中 `dim_fcdimen_c2` 分布：

| 类别 | 计数 |
|---|---|
| 3D | 15,376 |
| None | 11,174 |
| 2D | 3,057 |
| 0D | 1,838 |
| 1D | 1,760 |
| 混合（01D 501 / 02D 390 / 03D 756 / 12D 262 / 13D 371 / 23D 155 / 012D 22 / 013D 19 / 023D 8） | 2,484 |
| **低维合计（非 3D 非 None）** | **9,139** |

**对照论文**：9,139 = 1,838 (0D) + 1,760 (1D) + 3,057 (2D) + 2,484 (混合)，**逐一精确匹配**。

c1 与 c3 分布（见 `results/evidence_table.csv`）亦全部实测：c1 以 3D 为主（21,696）且 2D 仅 312；c3 中 0D 达 7,926。三者差异源于三套判据对 FCDimen 原始分数的不同聚合方式。

### 2.3 fcdimen_score 与标签的一致性（补充验证）

对 24,515 个有 `fcdimen_score` 的条目，`argmax(fcdimen_score)` 与三标签的一致性：
- 与 `c1`：11,039 / 24,515 = **45.0%**
- 与 `c2`：8,879 / 24,515 = **36.2%**
- 与 `c3`：24,515 / 24,515 = **100%**

即 **`dim_fcdimen_c3` ≡ `argmax(fcdimen_score)`（原始分数最高维）**；c1、c2 为更严格的聚合判据（c2 可在原始分数主维为 3D 时仍判定材料含 2D 结构单元，见 2D 库中 2,576 条 c1=3D 但 c2=2D）。论文头条分布使用 c2。

### 2.4 剥离能（E_exf）分析

`2D_materials.json` 中 2,988 条 E_exf（meV/Å²）统计：
- min **2.62**，Q1 92.7，中位 **152.6**，均值 172.2，Q3 215.8，max 1,179.8。
- 阈值分组（论文 35 / 125）：

| 类别 | 计数 | 其中库外新材料 |
|---|---|---|
| 易剥离（≤35） | **183** | **146** |
| 可能剥离（35–125） | **953** | **741** |
| 强结合（≥125） | 1,852 | 1,562 |
| 易+可能剥离 | **1,136** | **887** |

**对照论文**：易剥离 183、可能剥离 953、合计 1,136，以及「库外新材料 887 = 146 + 741」，全部与论文结论精确一致。`topo` 标记在冻结数据中为 0。

**已知性标记统计**（布尔计数，可重叠）：
- `matpedia=183, DBBs=216, c2db=127, robocrys=108, mc2d=83, rae=2, topo=0`。
- 库外新材料总数（所有标记全 False）：2,988 − 539 = **2,449**。
- 887 个易/可能剥离材料全部为库外新材料 ⇒ 支持「887 全部为已知 2D 数据库之外」的论断。

### 2.5 交叉验证

- `screened_materials.json` 中 c2=2D 共 **3,057** 个 mpid；`2D_materials.json` 的 2,988 个 mpid **全部**在其中（`2d_file_mpids_in_screened_c2_2d = 2,988`）。
- 有 **69** 个 c2=2D 材料未进入 `2D_materials.json`：其中 67 个 c1=3D、2 个 c1=2D；全部 stable；均值 ehull 0.0177 eV/atom。推测为单层抽取/结合能计算未完成或未通过，属论文口径差异（2D 库为 3,057 候选的子集）。
- Larsen 几何描述符：9,139 个低维材料的 Larsen 主维度全部为 3D ⇒ 支持「传统几何描述符无法识别这些低维材料」。

## 3. 与论文/任务锚的对照

| 锚 | 论文/任务值 | 冻结数据实测 | 结论 |
|---|---|---|---|
| UMLIP 基准材料数 | 35,689 | 35,689（`screened_materials.json` 条目） | 精确一致 |
| 筛选池 | 153,234 | **不在冻结文件**（冻结文件为 35,689 结果集） | 不可直接核验（论文正文：153,234 过滤后得到 35,689） |
| 动力稳定数 | 24,515 | 24,515 | 精确一致 |
| 低维材料总数 | 9,139 | 9,139（c2） | 精确一致 |
| 0D/1D/2D/混合 | 1,838/1,760/3,057/2,484 | 同左 | 精确一致 |
| 2D 材料 | 3,057（c2 计数） | 3,057（c2 计数）；2D 库 2,988 | 2D 库为子集 |

**主要口径差异**：任务 manifest 将 `screened_materials.json` 描述为「153,234 个筛选材料」，但冻结文件实测为 **35,689** 条。这与论文正文一致（"This screening finally gave us 35,689 materials"）——冻结文件保存的是过滤后的筛选结果集，而 153,234 是初始筛选池。因此「153,234」这一规模数字无法从冻结数据直接核验，但不影响 9,139 与 887 两项核心结论的复现。

## 4. 结论标签

**总体：`supported`**

- 论断 1（35,689 基准）：`supported`（计数精确；>10K 声子库对照不在数据内，不可核验部分不评）。
- 论断 2（9,139 低维发现）：`supported`（分布逐一精确复现）；「153,234 初始池」`inconclusive`（不在冻结文件）。
- 论断 3（887 可剥离新材料）：`supported`（精确复现，已知性标记核验）。
- 论断 4（数据库发布）：`supported`（文件存在、可解析、SHA-256 一致、字段与 README 相符）。

## 5. 局限

1. **153,234 初始池不在冻结数据**：无法独立验证论文「从 153,234 筛选」的输入规模与筛选损耗，只能核验过滤后的 35,689 结果集及其下游结论。
2. **>10K 声子数据库对照不在冻结数据**：论文「UMLIP 首性原理级精度」的声子验证部分无法用本包数据独立评估。
3. **E_exf 单位标注**：README 写 "meV/Å"，论文阈值口径为 meV/Å²。数值上与论文阈值分组（35/125）完全吻合，推测 README 单位标注为简写/笔误；本报告按论文口径（meV/Å²）使用阈值。
4. **FCDimen 三判据算法细节**：未复现论文的 c1/c2/c3 算法本身，仅直接使用数据中已给的标签并验证了 c3 = argmax(fcdimen_score)。c2 的具体聚合规则未从论文推导。
5. **69 个 c2=2D 未入 2D 库**：原因（单层抽取失败/结合能缺失等）需论文或补充数据确认。
6. **大文件解析**：采用 ijson 流式解析 `screened_materials.json`，仅抽取标量性质字段；未物化原子坐标/力（本任务统计不需要）。

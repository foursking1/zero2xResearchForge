# SCORE_RUBRIC：L1 判分标准（私有）

- 任务：`2312.01792_wildtab`（Wild-Tab 表格 OOD 泛化 critical claim）
- 判分模型：LLM 裁判（Claude / GLM 等均可；跨 agent 分数比较须使用同一裁判模型）
- 满分：100（A. 核心结果达成度 60 / B. 证据真实性 25 / C. 方法与报告 15）
- 判分流程：裁判读 TASK.md 与提交物 → 核对证据表数值 → 抽查重算 1-2 个关键数 → 按三维度打分。

## A. 核心结果达成度（60 分）

A 分由两个子锚（各 30 分）+ 方向性校验组成。锚值见 PAPER_ANCHOR.md（A1=1.741，A2=1.353）。

### A1. OOD 测试 MAE（锚 1.741 °C）— 30 分

| 报告值相对差 | 得分 |
| --- | --- |
| ≤5% | 30 |
| (5%, 15%] | 22 |
| (15%, 30%] | 15 |
| >30% | ≤8 |

### A2. ID 测试 MAE（锚 1.353 °C）— 30 分（同表）

### 方向性校验（claim 成立性）
- 若报告 OOD MAE ≤ ID MAE（无正向泛化差距，或 OOD 更优）→ A 总分直接 ≤20，结论应标注为 contradicted/inconclusive。
- 若报告了明显异常的样本量（与冻结数据文件行数不符，偏差 >5%）→ A 总分 ×0.8。

### 一致性交叉核对
- A3（gap 锚 28.6%）不单独计分：若 A1/A2 均准但 gap 明显不符（绝对差 >8pp），A 总分 ×0.9。

## B. 证据真实性（25 分）

- 提交必须含可运行代码 + 证据表（含 split、n、mae、gap_pct）——缺任一 → ≤10 分。
- 裁判抽查 1-2 个关键数（抽查字段：`eval_out` 的行数 n 与 OOD MAE；`eval_in` 的行数 n 与 ID MAE）：
  - 运行提交代码（或等价重算脚本）从 `data/` 冻结文件重算出该数，与证据表一致 → 25 分（满分）。
  - 可重算但证据表与代码输出不一致 → 15 分。
  - 代码无法运行 / 不读取冻结数据 / 数值疑似直接抄论文 → ≤8 分。
- 裁判重算基准：MAE = mean(|pred − target|)，target = `temperature` 列；n = 文件数据行数（不含表头）。

## C. 方法与报告（15 分）

| 检查点 | 分值 | 判分要点 |
| --- | --- | --- |
| 方法合理性 | 5 | 模型与预处理与 ERM/回归设定匹配；有明确超参与训练设置 |
| 防泄漏 | 5 | 标准化仅 train 拟合；eval 未参与选择/早停/调参；无未来信息 |
| 局限性与边界 | 5 | 说明冻结子集 vs 论文全量差异、种子敏感性、结论适用范围 |

- 明显泄漏（如用全量统计标准化、用 eval 选模型）→ C 总分 ≤5，并在结论中标记不可信。

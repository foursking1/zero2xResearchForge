## A. 核心结果达成度（60）
锚：SAT-6 OA = **93.9%**（摘要）。取 agent 证据表整体 accuracy。
相对差 `d = |OA_agent − 93.9| / 93.9`：

| d | 得分 |
|---|---|
| d ≤ 10% | 48–60（d≤5% 给 55–60） |
| 10% < d ≤ 30% | 30–47 |
| 30% < d ≤ 50% | 12–29 |
| d > 50% 或未报告 OA | 0–11 |

扣分/加分：未报告混淆矩阵/多数类基线 → −3；结论词与证据矛盾 → −5；训练策略/种子交代不清 → −3；附加分析（类别混淆、浅层 vs 深度）→ +3（封顶 60）。

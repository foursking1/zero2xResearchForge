## B. 证据真实性（25 分）

- 提交必须含可运行代码 + evidence_table.csv（dataset/model/rmse/wape/mae）+ report.md——缺任一 → ≤10 分。
- 裁判抽查 2 项，运行提交代码（或等价重算脚本）从冻结 gz 重算：
  1. **数据事实**：exchange_rate 7,588×8；electricity 26,304×321；solar_AL 52,560×137；
  2. **某模型 RMSE**：如 exchange_rate 的 GBRT(W-b) 或 GBRT(Naive)/ARIMA，与 agent 证据表一致。
- 计分：
  - 两项均可重算且与报告一致 → 25。
  - 每项不可重算/不一致 → 各扣 8-12 分。
  - 无代码/代码不可运行 → 扣 8 分；evidence_table 缺失或列不完整 → 扣 5-10 分。
  - 报告把论文数字当实测（抄数）→ B 直接 ≤10 分。

## 判定流程（judge 步骤）

1. 读 `TASK.md` → 确认提交物齐全（代码 + evidence_table.csv + report.md）。
2. 按 A1/A2/A3 判定（必要时从 report 核对子采样与聚合口径）。
3. 从冻结数据重算抽查 2 项 → 打 B。
4. 依 C1-C3 打 C。
5. 总分 = A+B+C；将得分与理由写入评测报告。

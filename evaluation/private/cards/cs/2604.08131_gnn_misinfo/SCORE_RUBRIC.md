# SCORE_RUBRIC：L1 判分标准（私有）

- 任务：`2604.08131_gnn_misinfo`（GNN vs 传统基线 虚假信息检测 critical claim）
- 判分模型：LLM 裁判（Claude / GLM 等均可；跨 agent 分数比较须使用同一裁判模型）
- 满分：100（A. 核心结果达成度 60 / B. 证据真实性 25 / C. 方法与报告 15）
- 判分流程：裁判读 TASK.md 与提交物 → 核对证据表数值 → 抽查重算 1-2 个关键数 → 按三维度打分。

## A. 核心结果达成度（60 分）

A 分由两个子锚（各 30 分）+ 方向性校验组成。锚值见 PAPER_ANCHOR.md（A1=91.9，A2=66.8）。

### A1. GraphSAGE 测试 F1（锚 91.9%）— 30 分

| 报告值相对差 | 得分 |
| --- | --- |
| ≤5% | 30 |

| >20% | ≤8 |

### A2. MLP 测试 F1（锚 66.8%）— 30 分（基线方差大，用绝对差）

| 报告值绝对差 | 得分 |
| --- | --- |

| (15, 25]pp | 15 |

### 方向性校验（claim 成立性）
- 若报告 GraphSAGE F1 ≤ MLP F1（无正向优势或方向相反）→ A 总分直接 ≤20，结论应标注为 contradicted/inconclusive。
- 若报告明显异常的样本量（与冻结 CSV 行数不符：72,134 行或 dropna 后 72,095 行，偏差 >5%）→ A 总分 ×0.8。

### 幅度一致性
- A3（+25.1pp 优势）不单独计分：若 A1/A2 均准但优势幅度 <15pp，A 总分 ×0.9（说明复现未达到论文幅度）。

## B. 证据真实性（25 分）

- 提交必须含可运行代码 + 证据表（含 model、split、n、f1、precision、recall、f1_gap_pp）——缺任一 → ≤10 分。
- 裁判抽查 1-2 个关键数（抽查字段：`graphsage` 的 test n 与 F1；`mlp` 的 test F1）：
  - 运行提交代码（或等价重算脚本）从 `F:\dataset\cs\2604.08131_gnn_misinfo\data\welfake\WELFake_Dataset.csv` 重算出该数，与证据表一致 → 25 分（满分）。
  - 可重算但证据表与代码输出不一致 → 15 分。
  - 代码无法运行 / 不读取冻结数据 / 数值疑似直接抄论文 → ≤8 分。
- 裁判重算基准：F1 = sklearn `f1_score(y_true, y_pred)`（weighted 或 binary 均可，需与报告口径一致）；n = test 集样本数。

## C. 方法与报告（15 分）

| 检查点 | 分值 | 判分要点 |
| --- | --- | --- |
| 方法合理性 | 5 | 模型与预处理与论文设定匹配（TF-IDF 5,000、k-NN 图 K=5、MLP 256/128）；有明确超参与训练设置 |
| 防泄漏 | 5 | TF-IDF 词表仅 train 拟合；test 未参与选择/早停/调参；图结构无 test 信息外泄 |
| 局限性与边界 | 5 | 说明单次/少种子运行 vs 论文 3 种子平均的差异、训练方差（MLP 尤其大）、结论适用范围 |

- 明显泄漏（如用全量拟合 TF-IDF、用 test 选模型、k-NN 图包含 test 节点特征）→ C 总分 ≤5，并在结论中标记不可信。

- 判分模型：Claude / GLM 等 LLM 裁判均可；证据重算由裁判运行提交代码完成。

## A. 核心结果达成度（60 分）

| 锚 | 论文值（出处） | 判分规则 |
|---|---|---|
| A1 RNA-only 性能 | RF acc 92.35±1.07% / 宏 F1 89.28±1.57%；XGBoost Balanced Acc 88.69±2.18% / AUC 95.61±1.50%（Table II/III） | 提交 RNA-only 最优模型的 Balanced Acc 落在 80-95% 且 AUC ≥0.85 → 满分；Acc 75-80% → 半满；更低或未报告 → 低分 |
| A2 多组学集成增益 | RF 集成 Balanced Acc 90.3% / AUC 97.1%（Abstract/Results） | 提交集成模型 AUC ≥ 单组学最优 AUC 且 Balanced Acc ≥85% → 满分；集成≥单组学但 Acc 80-85% → 半满；集成 < 单组学 → 低分 |
| A3 防泄漏影响 | 论文强调折内特征选择防泄漏（Results/§方法） | 提交泄漏对照（全数据选择 vs 折内）且差异方向合理（泄漏≥防泄漏）→ 满分；未做泄漏对照 → 半满 |

- 档位折算：每锚 20 分；满分 20 / 半满 10 / 低分 0-5；A 总分上限 60。

## B. 证据真实性（25 分）

- 提交必须包含 `code/` 与 `results/`；缺失 → B 直接 0。
- 裁判抽查 1-2 个关键数：
  1. **抽查字段 1**：`results/evidence_table.csv` 中 RNA-only RF（或最优模型）的 `roc_auc`。
  2. **抽查字段 2**：`results/metrics.json` 中样本数与 ER+ 比例。
- 裁判从冻结数据运行提交代码（或独立复核脚本）重算：
  - 能重算且一致 → 满分 25；
  - 有 1 个不一致（AUC 绝对差 >0.02）→ 12-20；
  - 无法重算/无代码/抄论文数字 → 0-10。

## C. 方法与报告（15 分）

- C1（5 分）方法合理：barcode 对齐、折内特征选择实现、模型与指标口径。
- C2（5 分）防泄漏：测试折未参与任何统计量估计；泄漏对照清晰。
- C3（5 分）报告：`report.md` 含方法、结果、局限（特征数与论文差异、样本对齐规则）与结论标签。

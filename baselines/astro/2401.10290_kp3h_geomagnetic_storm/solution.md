# Solution — 2401.10290：3 小时提前预测地磁暴 Kp 指数 RF 回归验证

- 设备：Windows 11，20 核 CPU；Python 3.13（numpy/pandas/sklearn）；`OMP_NUM_THREADS=4`，未用 GPU。
- 数据：`F:/dataset/astro/2401.10290_kp3h_geomagnetic_storm/`（NASA OMNI 5-min、GFZ Kp、京都 Dst、aux hourly 交叉验证源；SHA-256 固定）。
- 代码：`code/analyze_kp3h.py`（从冻结数据重算全部数字）。

## 1. 方法

1. **解析**：OMNI 5-min（105,120 行，7 个太阳风变量，缺失已转 NaN）；GFZ Kp（2,920 行，3 小时间隔，连续标度 0–9）；京都 Dst（8,760 行，逐时）。
2. **交叉验证**：aux hourly `kp_index/10` 与 GFZ Kp、`dst_index_nt` 与京都 Dst 逐时一致；2021-11-04 风暴峰值 GFZ Kp=7.667（09:00–12:00 区间）、Dst=−105 nT（13:00）。
3. **预测网格**：每 3 小时一个预测点 t（00/03/…/21 UTC），目标 = t+3h 起的 Kp 区间。特征全部来自 ≤t 的已观测数据（无未来泄漏）：
   - 太阳风 7 变量 × 108 滞后（0–535 min，5-min 步长）＝756 特征；
   - Dst 滞后 1/2/3 h＝3 特征；
   - Kp 滞后 3–24 h（3h 步长）＝8 特征。
   - 合计 767 特征。5-min 数据前向填充 + 全局中位数补缺；Dst/Kp 缺失行剔除。
4. **切分**：train = Jan–Sep（2,184 事件）、test = Oct–Dec（735 事件）。
5. **模型**：RF 回归 100 树（max_features=p/3），全特征 / top-100 / top-50 / top-50+下采样（L=2，训练期对 Kp<3 样本丢弃一半）。基线：持久性（最新已知 Kp=t−3h 区间值）、均值、中位数。
6. **指标**：accuracy = test 期 `|pred−actual|≤1` 的比例；RMSE。特征重要性衰减：太阳风近端（≤15 min）vs 远端（495–505 min）均值。

### 2.4 与论文 82.55% 的差距归因

1. 特征构造细节未公开（论文 780 维 vs 本工作 767 维，差 13 维——论文可能含额外的时滞/辅助特征）。
2. 缺测处理（论文未说明；本工作前向填充+中位数）。
3. 事件网格（论文 2,679 事件 vs 本工作 2,919；warm-up 处理不同）。
4. 下采样/随机种子差异。

## 3. 结论与判定

**partially_supported**：3 小时提前 Kp 预测技能在冻结数据口径下被复现（accuracy 75.4% 显著高于均值基线，与论文同量级）；"特征重要性随滞后快速衰减"被复现（近/远比 7.18≥2）。论文精确值 82.55% 未在冻结口径下精确复现（细节差异所致）。

## 4. 局限

- 特征构造/预处理与论文不完全一致（见 2.4），不可精确复现 82.55%。
- 下采样消融结论与论文相反（论文称提升，本工作与编译器探针均显示下降），可能因下采样口径或特征集差异。
- 中位数插补对高 Kp 事件有压缩效应；RMSE 受强扰动影响。
- 5-min 太阳风缺失 5–9%，前向填充引入一定自相关。

## 关键设计决策与对锚的影响

- **冻结数据为官方 100 Hz 全量 parquet**（论文 Table VI 即 100 Hz 结果，§V-B "We have used a sampling frequency of 100 Hz for all methods"）→ 数据口径与论文一致。
- 论文锚 93.6 为 MVT-Flow（特定正常流架构 + 超参 + GPU 训练 9 次平均）。agent 若实现等价深度密度/重构方法（VAE/AE 等），平均 AUROC 预计落在 80-92 区间；A1 的 ±5pp/±10pp 带宽已为此预留（85-93 可获 22-30 分）。
- 若 agent 只做 PCA/1-NN 基线（~77-80），A1 得分约 6-14 分、A2 低分 → 总分自然落低档，符合 L1 难度设计（需实现深度方法才拿高分）。
- 类别特异性（A3）是 L1 辅助锚：miss_can 被简单方法完美检测、entangled/invalid_position 需深度方法——要求 agent 同时跑基线与深度方法才能回答 claim (c)，天然增加难度。
- **风险**：GPU 需求可能阻碍部分 agent → rubric C 维度允许 CPU 可实现的小型深度方法（如 LSTM-AE/CAE）并给足方法合理性分数；A1 带宽覆盖。

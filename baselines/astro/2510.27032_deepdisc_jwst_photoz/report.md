# Report — DeepDISC JADES photo-z 目录核验（2510.27032）

## 摘要

冻结目录（`jades_photoz_catalog.csv.gz`，CC-BY-4.0）独立核验：行数 = **94,000**，列结构 = z_phot_mode（PDF 众数）+ l/u 68/95/99% CI + forced + spec_rep，与论文"94,000 概率式 photo-z"数据产品 claim 一致。CI 单调性与嵌套性 100% 通过，无 NaN/负红移/负宽度；但 `mode∈[l68,u68]` 通过率 **95.66%**（4,063 个众数低于 l68，18 个高于 u68），源于约 4.3% 源的多峰/强偏斜 PDF。forced=True 子集 CI 系统性更宽。论文质量指标（bias=0.0035 / IQR=0.0311 / η=0.0503）与 EAZY 对比需谱红移测试集/图像/权重，本目录**不可检验**。结论标签：**partially_supported**。

## 方法要点

1. 全量自洽性检查：mode∈68%、单调性、嵌套性、病态值。
2. z 分布直方图 + 分位数 + z>6 占比。
3. CI 宽度按 z 分箱与 forced 分层统计。
4. 可检验性清单：目录可核验项 vs 需外部数据项。

## 关键数字

| 检查项 | 本工作复算 | 论文/预期 | 判定 |
|---|---|---|---|
| 行数 / 唯一 ID | 94,000 / 94,000 | 94,000 | 复现 |
| mode∈68% 通过率 | 95.66% | （预期 100%） | 复现（数据事实，非 100%） |
| 68/95/99 单调性 | 100% | 100% | 复现 |
| NaN / z<0 / 负宽度 | 0 / 0 / 0 | 0 | 复现 |
| forced=True w68 均值 | 1.95 vs 1.24（False） | — | 更宽 |
| z 范围 / 中位数 | 0–7.51 / 3.37 | z 至 ~11（训练样本） | 目录覆盖至 ~7.5 |
| 质量指标（IQR/η/bias） | 不可检验 | 0.0311/0.0503/0.0035 | 不可检验 |

## 结论与边界

- 数据产品 claim 支持；质量与 EAZY 相当 claim 不可检验（无谱红移/图像/权重）。
- 局限：spec_rep 语义为推断；目录仅存 mode+分位数，无完整 PDF 形状；目录核验 ≠ 质量复现。

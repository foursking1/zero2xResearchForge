## 判分对照速查（judge 用）

- agent 实测 Linear MAE ∈ [0.16, 0.25] 且 C1 排序成立 → A 满分 60。
- agent 实测 Linear MAE ∈ 半满带或排序错（如 LOCF < Linear）→ A=30 及以下。
- B 抽查两数：(1) test 掩码点总数 2,385（或与 agent 掩码协议一致的可重算值）；(2) Linear test MAE（从 agent 代码+冻结数据重算，须与报告一致，相对差 ≤1e-6）。
- C 维度重点：是否混淆"论文引用深度数值"与"实测简单基线"；是否说明掩码/划分口径差异；结论四档标签是否与证据匹配。

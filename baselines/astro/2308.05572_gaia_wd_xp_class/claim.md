# Claim — 2308.05572_gaia_wd_xp_class

## 可证伪科学声称（一句话）

论文核心论断：基于 Gaia DR3 XP 光谱的 ML 分类将 **100,886** 个高置信白矮星候选（PWD>0.9、G<20.5）分为六类（DA/DB/DC/DO/DQ/DZ）；置信阈值 0.65 下得到 **89,188** 个 high-confidence 分类、**11,698** 个 uncertain；各类数量（Table 2）**DA 77,330 / DB 5,688 / DC 4,082 / DO 215 / DQ 601 / DZ 1,272**，**DA 占绝对主导**（76.65%）。

## 失败条件

- 若总行数 ≠ 100,886 或唯一 GaiaDR3 源数 ≠ 行数 → 样本规模 claim 未复现。
- 若 SpType 无冒号口径六类计数与 Table 2 差异显著（>5%）或总数 ≠ 89,188 → 分类组成 claim 未复现。
- 若 DA 占比偏离 76.65% 过远（>±1pp 且无法归因）→ DA 主导子论断未复现。

## 结论标签

**supported**

- 样本规模：**精确复现**——总行数 = 唯一 GaiaDR3 源数 = **100,886**。
- 分类组成：**精确复现**——SpType 无冒号口径六类计数 **DA 77,330 / DB 5,688 / DC 4,082 / DO 215 / DQ 601 / DZ 1,272**，合计 **89,188**；带冒号 uncertain **11,698**，与论文 Table 2 完全一致。
- DA 主导：**复现**——DA 占比 76.65%，high-confidence 占比 88.40%，与论文一致。
- argmax(PDA..PDZ) 口径（含 low-confidence 对象）≠ Table 2（DA 83,963），差异来源为两位小数舍入与 uncertain 对象；冒号标注基于未舍入概率，故以 SpType 冒号规则为准。
- 参数化完整性：Teff=-999 为 **1,396**（论文 1,080）、DA Teff>300,000 K 为 **68**（high-conf 子集 54；论文 34）——与论文存在发布版本漂移，如实报告。
